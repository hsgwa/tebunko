## 16. テスト

### 16.1 単体テスト（Pester）

`tests/search.Tests.ps1` で、12 章の `common.ps1` の関数のうち検索・Office プロセス・画面用のものを確認する（`getTargetFolders` などは `tests/common.Tests.ps1`）。切り出し時（`grep.ps1` の削除前）に、`grep.ps1` が切り出しの前後で同じテストデータ・検索ワード（文字どおり・正規表現・不正な正規表現・0 件、複数インデックス・存在しないフォルダ）の結果ファイルとコンソール出力がバイト単位で同じことを確認した。

| 対象 | 主な確認内容 |
|---|---|
| `searchIndex` | 文字どおり・正規表現・不正な正規表現、大文字・小文字（区別しない・区別する）、対象ファイル（含める・`!` で除く）、検索中に削除された TSV を飛ばす、複数フォルダ・入れ子の重複、上限での打ち切り、`[` `]` を含むパス |
| `newSearchRegex` | 文字どおりの記号、不正な正規表現、大文字と小文字の区別 |
| `newFileFilter` | `;` / `；` の区切り、`!` の除外、部分一致、`?`、ほかの記号は文字どおり、空なら条件なし |
| `writeSearchResult` | [02_検索.md](02_検索.md) の結果ファイルの形式になること |
| `splitTsvCells` | `"` で囲まれたセル内のタブ、空のセル、先頭のセルが空の行 |
| `readTsvContext` | 前後の行と行番号、セル内改行の文字では行を分けない、ファイルの先頭・末尾、1 行だけでも配列、ファイルが無ければ空、CRLF・LF・CR の混在（検索と同じ行番号）、BOM の有無、最後の行に改行が無いファイル、TSV が書き換わったら読み直す |
| `searchIndex` の結果 | `@()` で配列にできること、中止・進捗の通知 |
| `getIndexTsvFiles` / `testIndexExists` / `getIndexSummary` | TSV の列挙・件数・最新の更新日時、存在しないフォルダ、入れ子のフォルダの重複、インデックスの中のフォルダだけの指定（相対パスはインデックスのフォルダから）、直下のファイルだけの指定、存在しない中のフォルダ、数え上げの途中の件数の通知（2000 件ごと。少数では呼ばれない） |
| `readSearchOption` / `writeSearchOption` | ファイルが無ければオフ・空、保存した値の読み込み、指定した項目だけを変える |
| `getOfficeProcesses` / `stopOfficeProcesses` | バックグラウンドの判定、終了の成功・失敗（`Get-Process` / `Stop-Process` をモックする） |
