# インデックス作成ログの警告・お知らせ一覧（まとめ・置き場・後片付け）

扱うこと: インデックス作成が続けながら `work/indexing_log.txt` に書く警告・お知らせのうち、インデックスのまとめ・gram 索引・目録・前の版のインデックス・作業フォルダの後片付けに関するもの。扱わないこと: 取り込みの途中の警告（[警告・お知らせ一覧](log-warnings.md)）・インデックス作成を止めるエラー（[エラーメッセージ一覧](errors.md)）。先に読むページ: [警告・お知らせ一覧](log-warnings.md)。

利用者に出す警告・お知らせの文言を足したら、この一覧か [警告・お知らせ一覧](log-warnings.md) に載せる（`tests/meta/error_messages.Tests.ps1` が、`writeIndexerLog` に Yellow・Red で渡す文言が載っているかを確かめる）。メッセージ中の `<…>` は実行時に埋め込む値。

| メッセージ | 発生条件 |
|---|---|
| `インデックスをまとめられませんでした（次のインデックス作成でまとめ直します）: <メッセージ>` | 取り込み済みのフォルダを本文インデックスにまとめる処理が失敗した（`flushPendingPublish`）。次のインデックス作成でまとめ直す |
| `    大きすぎるインデックスのファイルを外しました（<インデックスからの相対パス>）。中の <N> 件は次の更新で取り込み直します` | 前の版が作った、検索の上限（64MB）を超える本文インデックスのファイルを、書き出しのときに外した（`publishIndexFolders`）。中の元のファイルは取り込み一覧で「未取り込み」に戻り、次の更新で取り込み直す |
| `インデックスの置き場の外を指すパス（途中のリンクを含む）のため、書き出しませんでした: <パス>` | 本文インデックスを置くパスが置き場の外を指す・途中にリンクがある（`publishIndexFolders`）。そのフォルダは書き出さず続ける |
| `インデックスにまとめられなかったフォルダがあります（<段>）: <相対パス>: <理由>。インデックスを作り直すと直ります` | 本文インデックスにまとめる処理が、1 つのフォルダで止まった（`publishIndexFolders`）。ほかのフォルダは続ける |
| `取り込めませんでした（次の更新で取り込みます）: <メッセージ>` | 1 フォルダ分の取り込みの後始末（結果の書き込み）が失敗した（`completeIngestJob`）。そのフォルダは次の更新で取り込み直す |
| `gram 索引を作れませんでした（<インデックス名>。次のインデックス作成で作り直します）: <理由>` | 1 つのインデックスの gram 索引（[gram 索引](../index-data/gram-index.md)）を作れなかった。次のインデックス作成で作り直す |
| `gram 索引を作れませんでした（次のインデックス作成で作り直します）: <メッセージ>` | gram 索引を作る処理そのものが例外で止まった。次のインデックス作成で作り直す |
| `インデックスの目録を書けませんでした（古い形式の分は消していません）。` | インデックスの目録（形式の記録）を書けなかったため、古い形式のインデックスを消さずに残した |
| `インデックスの目録を書けませんでした（新しい版の tebunko で作られた可能性があります）。` | インデックス作成の始めに目録を書けなかった。新しい版の tebunko で作られたワークスペースの可能性がある |
| `古い形式のインデックスを消せませんでした（次のインデックス作成の終わりにもう一度消します）: <パス>` | 新しい形式に作り直したあと、古い形式のインデックスのフォルダを消せなかった |
| `前の版のインデックス（「<フォルダ>」）は、この版では使えません。［すべて更新］で、元のファイルをすべて更新し直します。` | 前の版が作ったインデックスのフォルダが見つかった。この版では使わない |
| `更新し直した後、「<フォルダ>」フォルダは削除してかまいません。` | 上の行に続けて書く。更新し直したあとは、前の版のフォルダを手で消してよい |
| `前の版が作った検索用のファイルを消せませんでした（<原因>）。次のインデックス作成でもう一度消します。` | 前の版が作った検索用のファイルのフォルダを消せなかった |
| `インデックス「<名前>」: <状態の文言>` | インデックスの形式の状態に、利用者が知っておくべきことがある（古い形式・新しい版で作られたもの等。[インデックス一覧の管理](../gui/index-tab.md)の状態の文言と同じ） |
| `取り込み一覧に読めない行が <N> 行ありました（無視しました）。` | `work/store/ingest_status.tsv` に、形が崩れて読めない行があった。その行は無視して続ける |
| `設定に無いインデックス（<名前>: <パス>）は削除せずに残しました。画面の［すべて更新］で確認して削除できます。` | 画面の設定から消えたインデックスのフォルダが、置き場に残っている。勝手に消さず、［すべて更新］の確認で消せる |
| `クラウドにだけあるファイル <N> 件は、ダウンロードせずに残します。（次のインデックス作成でも確かめます）` | OneDrive などでクラウドにだけあるファイルを見つけた。ダウンロードさせないため取り込まない |
| `インデックス作成を中止しました。（成功: <N> 件 / 失敗: <N> 件）` | 画面の［中止］で止めたあとの、取り込んだ件数のまとめ（終了コード `2`） |
| `PowerPoint のために取り込めなかった <N> 件は、PowerPoint を閉じてからもう一度更新すると、そのまま取り込みます。` | 利用者の PowerPoint が起動していたため取り込めなかったファイルがある（取り込み一覧の `PowerPoint が起動していたため…` の件数のまとめ） |
| `    作業フォルダがリンク（ジャンクション・シンボリックリンク）のため、中のファイルを消しませんでした: <パス>` | 作業領域（`work/tmp/<PC の鍵>/<PID>`）がリンクだった。リンクの先を消さない（`clearTmpDir`） |
| `    作業フォルダを削除できませんでした: <パス>（置き場の外か、途中にリンクがある）` | 作業領域を削除するとき、置き場の外を指す・途中にリンクがあった（`removeTmpDir`）。消さずに続ける |
| `    作業フォルダがリンク（ジャンクション・シンボリックリンク）のため、取り込みの作業フォルダを置けません: <パス>` | 取り込みのスレッドの作業フォルダを置く場所（`work/tmp/<PC の鍵>`）がリンクだった（`newWorkerTmpDir`）。その作業フォルダは使わない |
| `    終了したプロセスの作業フォルダを削除できませんでした: <パス>（置き場の外か、途中にリンクがある）` | 前の（終了済みの）プロセスの作業フォルダを片付けるとき、置き場の外を指す・途中にリンクがあった |
| `クロール対象から削除されたフォルダ（<パス>）のインデックス名が使えないため、削除しませんでした。` | 画面から外されたフォルダのインデックスを消すとき、インデックス名が使えない名前だった（`removeDroppedFolders`）。そのインデックスは消さない |
