# 画面に出すメッセージの一覧

扱うこと: 画面が出すメッセージ・確認・ダイアログの文言と条件の**正本**の入口。画面に出す文言は、このページと下の画面ごとのページにだけ書き、ほかの設計書は節へのリンクで指す（書き写すと食い違う）。扱わないこと: 確認ダイアログの形式そのもの（[画面の共通の決まり](common.md#確認ダイアログshowconfirm)）。先に読むページ: [画面の共通の決まり](common.md)。利用者に出す文言を足したら、画面ごとのページに載せる（`tests/meta/error_messages.Tests.ps1` が `messages*.md` を確かめる）。

## 画面ごとのページ

| 画面・場面 | ページ |
|---|---|
| ［インデックス管理］（一覧・詳細・追加・編集・削除・更新の確認・拡張子） | [messages-index.md](messages-index.md) |
| インデックスの書き出し・読み込み・名前変更・ワークスペースの変更で断られたとき | [messages-index-ops.md](messages-index-ops.md) |
| ［検索］・検索結果から開く・コピー・出力 | [messages-search.md](messages-search.md) |
| ［設定］（エディタの指定） | 下の「設定」 |
| 画面全体（状態・残った Office・予期しないエラー・起動の失敗） | 下の「画面全体」 |

## ログの文言

画面のログ欄・ファイルに書くインデックス作成のログの文言の正本は、[エラーの一覧（errors.md）](../indexing/errors.md)と、警告・お知らせの[log-warnings.md](../indexing/log-warnings.md)にある。ここには移さない。予期しないエラーを記録するファイル `gui_error_log.txt` に書く文は、下の「予期しないエラー」の行（ダイアログと同じ文）が正本で、ファイルの置き場と形は[入出力ファイル](../structure/io-files.md)にある。コンソールの出力は扱わない。

## 設定

| 表示場所 | 条件 | 文言 |
|---|---|---|
| ステータス | テキストをエディタで開いた | `エディタで開きました：<パス>` ／ 開けなかったとき `エディタで開けませんでした：<パス>`（既定のアプリには戻さない） |
| ステータス | 設定のエディタ（`textEditorPath`）が、スクリプトを動かすプログラムなので、メモ帳で開いた | 上の文の後ろに `設定のエディタ（textEditorPath）は、スクリプトを動かすプログラムのため使えません。メモ帳で開きます。` を足す |
| ステータス | 設定のエディタ（`textEditorPath`）が使えない（形が正しくない・ファイルが無い）ので、メモ帳で開いた | 上の文の後ろに `設定のエディタ（textEditorPath）が使えないため、メモ帳で開きます。` を足す |
| 行の下の赤字 | ［設定］の「エディタ」・ダイアログ「テキストの開き方」の下の行で、選んだ .exe が拒む表・版の情報の元の名前に当たる | `このプログラムはスクリプトを動かせるため、エディタにできません。`（保存しない。次に［変更…］を押す・選べたときに消える） |
| 行の下の赤字 | 同じ行で、選んだファイルの形が違う（UNC・相対・.exe でない）・ファイルが無い・版の情報を読めない | `このファイルはエディタに指定できません。ドライブから始まる場所にある .exe を選んでください。`（保存しない） |
| 説明 | ダイアログ「テキストの開き方」の上の説明 | `検索結果・プレビューからテキストファイルを開くときの開き方を、拡張子ごとに選びます（全インデックス共通）。「エディタで開く」は、下の「エディタ」のアプリ（既定はメモ帳）で開きます。取り込むかどうかは、インデックスの更新の確認で、インデックスごとに選べます。` |

## 画面全体

| 表示場所 | 条件 | 文言 |
|---|---|---|
| インデックスの状態 | [インデックスとインデックス作成の状態](state-flow.md#インデックスとインデックス作成の状態) のとおり | [インデックスとインデックス作成の状態](state-flow.md#インデックスとインデックス作成の状態) のとおり |
| インデックス作成の進み具合 | 確認待ち / インデックス作成中 / 終わった | [インデックス作成の進み具合](indexing-run.md#更新の進み具合)・[中止・終了・ログ](indexing-run.md#中止終了ログ) のとおり |
| ステータス | 残った Office を終了した / 変わっていて止めなかった / できなかった | `Office を N 件終了しました。` / `PID <N> は確認の後に別のプロセスに変わったため、終了しませんでした。` / `PID <N> を終了できませんでした：<理由>`（[起動時の確認](leftover-office.md)） |
| ダイアログ | [［インデックス管理］タブ](index-tab.md)の［＋ フォルダを追加］（追加できないときのメッセージ）・詳細の名前とフォルダパスの欄・［削除］、[インデックス作成の確認ダイアログ](indexing-run.md#インデックス更新の確認ダイアログ)（インデックス作成の確認）、[中止・終了・ログ](indexing-run.md#中止終了ログ)（インデックス作成の中止・インデックス作成中に閉じる・インデックスを作成できなかった）、[元のファイルが見つからないとき（元のフォルダを設定する）](open-file.md#元のファイルが見つからないとき元のフォルダを設定する)（元のファイルが見つからないとき）、[前回残った Office の確認](leftover-office.md#確認ダイアログ)。確認のものは [確認ダイアログ](common.md#確認ダイアログshowconfirm) の形式で出す（[インデックス作成の確認ダイアログ](indexing-run.md#インデックス更新の確認ダイアログ) は一覧を見せるため専用のダイアログ） | 各節のとおり |
| ダイアログ | 予期しないエラー（保存に失敗したなど。イベントの処理の外で起きた例外・XAML の描画中に WPF が投げる例外も同じ形で知らせる） | `エラーが発生しました。<例外メッセージ>`（ステータスにも `エラーが発生しました：<例外メッセージ>`。内容はワークスペースの `gui_error_log.txt` にも残す。同じ例外のダイアログは画面を開いている間に 1 回だけ、記録は 60 秒に 1 回まで） |
| ダイアログ | 多重起動で、すでに開いている画面に知らせられない（以前の版が開いている等） | `すでに開いています。`（知らせられたときは、そのウィンドウを前面に出すだけで、何も表示しない） |
| ダイアログ | 画面が出る前（`gui.ps1` の `try` の `catch` が呼ぶ `reportStartupFailure`）の起動の失敗。`shared.ps1` の読み込む部品が無いなど、メッセージボックスは出せるがまだ `writeErrorLog` が無い場面 | `予期しないエラーが発生しました。<例外メッセージ>`（記録のファイル名を残せたときは「詳しい内容は <ファイル名> に残しています。」を続ける。`writeErrorLog` が使えれば `gui_error_log.txt`、無ければツールのフォルダの `startup_error.txt`（書き込めなければ記録は残らない。[起動に失敗したときの知らせ](../../safety/disclosure.md#起動に失敗したときの知らせtebunkobat)）。メッセージボックス自体を出せない場面（制限言語モード・WPF が読めない）は `tebunko.bat` が Notepad で示す） |
