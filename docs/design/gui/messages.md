# 画面に出すメッセージの一覧

扱うこと: 画面が出すメッセージ・確認・ダイアログの文言と条件の一覧。扱わないこと: 確認ダイアログの形式そのもの（[画面の共通の決まり](common.md#確認ダイアログshowconfirm)）。先に読むページ: [画面の共通の決まり](common.md)。

## メッセージ一覧

| 表示場所 | 条件 | 文言 |
|---|---|---|
| 一覧の中 | インデックスが 1 件も無い | `インデックスがありません。［追加…］で、Office ファイルのあるフォルダを指定してください。` |
| 一覧の「フォルダの状態」 | フォルダがある / 無い / 調べている | `✓ フォルダがあります` / `✗ フォルダが見つかりません` / `… フォルダを確認しています` |
| 追加・編集のダイアログ | 入力に誤りがある | [追加・編集のダイアログ](index-tab.md#追加編集のダイアログ) のとおり（ダイアログ内に赤字） |
| ステータス | インデックスを追加した | `インデックス [<名前>] を追加しました。［インデックス作成を開始］を押すと中身を取り込みます` |
| ステータス | 追加したがフォルダが無い | `インデックス [<名前>] を追加しましたが、フォルダが見つかりません：<パス>` |
| ステータス | 同じフォルダのインデックスがある | `「<パス>」のインデックス [<名前>] は既にあります` |
| ステータス | インデックスを編集した | `インデックスを変更しました（名前 [<旧>] → [<新>] / 場所 <旧> → <新>）` |
| ステータス | インデックスを削除している（別スレッド） | `インデックス [<名前>] を削除しています…（件数によっては少し時間がかかります）` |
| ステータス | インデックスを削除した | `インデックス [<名前>] を削除しました` |
| ステータス | 削除に失敗した | `インデックス [<名前>] の削除に失敗しました：<メッセージ>` |
| ステータス | クロールしている | `クロールしています…` |
| ステータス | 確認で［インデックス作成を開始］を押した / 取りやめた | `インデックス作成を開始しました` / `インデックス作成を取りやめました` |
| 確認 | インデックスの削除 | [［1 インデックス管理］タブ](index-tab.md) No.4 のとおり |
| 確認 | インデックス作成の内容 | [インデックス作成の確認ダイアログ](indexing-run.md#インデックス作成の確認ダイアログ) のとおり（インデックスごとの取り込み対象の件数） |
| 警告 | インデックス作成中に追加・編集・削除しようとした | `インデックス作成中はインデックスを<追加／編集／削除>できません。インデックス作成が終わるまでお待ちください（［中止］で止められます）。` |
| 警告 | 前のインデックスの削除中に操作しようとした | `前のインデックスの削除が終わるまでお待ちください。` |
| インデックスの状態 | [インデックスとインデックス作成の状態](state-flow.md#インデックスとインデックス作成の状態) のとおり | [インデックスとインデックス作成の状態](state-flow.md#インデックスとインデックス作成の状態) のとおり |
| インデックス作成の進み具合 | 確認待ち / インデックス作成中 / 終わった | [インデックス作成の進み具合](indexing-run.md#インデックス作成の進み具合)・[中止・終了・ログ](indexing-run.md#中止終了ログ) のとおり |
| 検索ワード欄の下 | 正規表現オンで不正なワード | `正規表現として不正なため、文字どおり検索します。` |
| 件数（No.5） | 本文インデックスを数えている / 検索中 / 完了 / 絞り込み中 | `検索対象のファイルを確認しています…（N 件）` / `検索中… N / M ファイル（K 件）` / `N 件（M ファイル） ・ X 秒` / `N 件中 K 件を表示` |
| 件数（No.5） | 0 件 | `見つかりませんでした。`（正規表現オフで記号を含むワードなら `（正規表現として探す場合は［正規表現を使う］をオンにしてください）` を添える。そうでなく、既定から変えた検索条件があれば `（検索条件：大文字と小文字を区別・対象ファイル：<指定>・図形を除く・コメントを除く）` のうち当てはまるものを添える） |
| 件数（No.5） | 対象ファイルに一致するファイルが無い | `対象ファイル（<指定>）に一致するファイルがありません。` |
| 件数（No.5） | 検索対象に本文インデックスが無い | `検索対象のインデックスがありません。先にインデックスを作成してください。` |
| ステータス | 検索ワードが空 / 検索対象にチェックが無い | `検索ワードを入力してください。` / `検索するフォルダに、左の「検索対象」でチェックを付けてください。` |
| ステータス | 検索が終わった | `検索しました（<ワード>：N 件）`。既定から変えた検索条件があれば `検索しました（<ワード>：N 件　条件：<条件>）` |
| ステータス | 正規表現の照合が終わらない（1 行 5 秒超） | `検索できませんでした：正規表現の照合に時間がかかりすぎるため、検索を中止しました。正規表現を見直してください。`（No.5 は `検索できませんでした`） |
| ステータス | 中止した / 上限に達した | `中止しました（N 件まで表示）` / `10,000 件を超えたため、ここで打ち切りました。この先のファイルは検索していないため、ワード・対象ファイル・検索対象で絞り込んでください。` |
| ステータス | 見つからない検索対象フォルダがあった / インデックス作成中に検索した | 上の文に続けて `見つからない検索対象フォルダ：<パス>` / `インデックス作成中のため、作成途中のインデックスを検索しています。` を添える |
| 確認 | 元のファイルが無い・元の場所が分からない | フォルダを選ぶかの確認（[元のファイルが見つからないとき（元のフォルダを設定する）](open-file.md#元のファイルが見つからないとき元のフォルダを設定する) のメッセージ） |
| ステータス | 元のファイルが無い（フォルダを選ばなかった） | `元のファイルが見つかりません：<パス>` |
| ステータス | 選んだフォルダ・別の書き方のパスで見つかった | `インデックス [<名前>] の元のフォルダを <フォルダ> に変えました`（続けて開いた結果で上書きされる） |
| ステータス | 元のファイルを開いた | `開きました：<パス>` / `読み取り専用で開きました：<パス>` / `新規で開きました：<パス>`（Excel で該当セルへ移動できなかったときは `（該当セルへの移動はできませんでした）` を付ける。[元のファイルを開く](open-file.md)） |
| ステータス | 行・セル・パスをコピーした | `N 行をコピーしました（Excel に貼り付けると、元の列の位置に並びます）` / `セルの値をコピーしました：<値>` / `N 個のセルをコピーしました（Excel に貼り付けると、元の位置に並びます）` / `パスをコピーしました：<パス>` |
| ステータス | 結果を出力した / 書き込めない | `検索結果.txt に出力しました（N 件）`（絞り込み中は `絞り込み後の N 件を検索結果.txt に出力しました`） / `検索結果.txt に書き込めません。開いているアプリを閉じてから、もう一度出力してください。` / `検索結果.txt に書き込む権限がありません（読み取り専用など）。<パス> を確かめてから、もう一度出力してください。`（[結果をファイルに出力](search-tab.md#結果をファイルに出力)） |
| ステータス | プロセスを終了した / できなかった | `N 個のプロセスを終了しました。` / `PID <N> を終了できませんでした：<理由>` |

| ダイアログ | [［1 インデックス管理］タブ](index-tab.md)の［追加…］［編集…］［削除］、[インデックス作成の確認ダイアログ](indexing-run.md#インデックス作成の確認ダイアログ)（インデックス作成の確認）、[中止・終了・ログ](indexing-run.md#中止終了ログ)（インデックス作成の中止・インデックス作成中に閉じる・インデックスを作成できなかった）、[元のファイルが見つからないとき（元のフォルダを設定する）](open-file.md#元のファイルが見つからないとき元のフォルダを設定する)（元のファイルが見つからないとき）、[終了の確認](process-tab.md#終了の確認)。確認のものは [確認ダイアログ](#確認ダイアログshowconfirm) の形式で出す（[インデックス作成の確認ダイアログ](indexing-run.md#インデックス作成の確認ダイアログ) は一覧を見せるため専用のダイアログ） | 各節のとおり |
