# 画面に出すメッセージの一覧

扱うこと: 画面が出すメッセージ・確認・ダイアログの文言と条件の一覧。扱わないこと: 確認ダイアログの形式そのもの（[画面の共通の決まり](common.md#確認ダイアログshowconfirm)）。先に読むページ: [画面の共通の決まり](common.md)。インデックスの書き出し・読み込み・名前変更・ワークスペースの変更で断られたときのエラーは[インデックスの書き出し・読み込み・ワークスペースのエラー](messages-index-ops.md)にある。利用者に出す文言を足したら、この一覧かそちらに載せる（`tests/meta/error_messages.Tests.ps1` が確かめる）。
