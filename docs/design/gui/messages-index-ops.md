# インデックスの書き出し・読み込み・名前変更・ワークスペースのエラー

扱うこと: インデックスの書き出し（エクスポート）・読み込み（インポート）・名前の変更・削除、ワークスペースの変更、設定の保存と読み込みで、操作が断られたときに画面に出すエラーの文言と条件。扱わないこと: 画面のメッセージ全般（[画面に出すメッセージの一覧](messages.md)）、置き場の安全確認のエラー（[置き場の安全確認のエラー](../indexing/errors-store.md)）。先に読むページ: [画面に出すメッセージの一覧](messages.md)・[インデックス一覧の管理](index-tab.md)・[［設定］タブ](settings-tab.md)。

操作が断られたとき、例外のメッセージをそのまま画面のエラー（［インデックス管理］の帯・確認のダイアログ・［設定］の欄）に出す。メッセージ中の `<…>` は実行時に埋め込む値。利用者に出すエラーの文言を足したら、この一覧か[画面に出すメッセージの一覧](messages.md)・[エラーメッセージ一覧](../indexing/errors.md)に載せる（`tests/meta/error_messages.Tests.ps1` が確かめる）。

## インデックスの書き出し（エクスポート）

| 表示場所 | 条件 | 文言 |
|---|---|---|
| エラーの帯・ダイアログ | インデックス作成の実行中に書き出そうとした | `更新中はエクスポートできません。更新が終わってからやり直してください。` |
| 同上 | 書き出し先のフォルダが無い | `書き出し先のフォルダが見つかりません：<パス>` |
| 同上 | 書き出すインデックスが、設定・置き場に無い | `インデックス [<名前>] が見つかりません。` ／ `取り込み一覧に、インデックス [<名前>] の記録がありません。` |
| 同上 | インデックスのフォルダを最後まで読めなかった | `インデックスのフォルダを最後まで読めませんでした: <パス>` |
| 同上 | 更新が終わっておらず、インデックスにならないファイルが残っている | `インデックスとして扱えないファイルが残っています（<ファイル名>）。更新を最後まで行うか、そのファイルを取り除いてからエクスポートしてください。` |

## インデックスの読み込み（インポート）の zip の確認

zip を開く前に、目録（zip の中の `manifest` の記録）と中身を突き合わせて、tebunko が作った zip かを確かめる。

| 表示場所 | 条件 | 文言 |
|---|---|---|
| エラーの帯・ダイアログ | tebunko の zip でない・壊れている | `tebunko のインデックスの zip ではない、または壊れています（<詳細>）。` ／ `tebunko のインデックスの zip ではない、または壊れています（目録を読めません）。` ／ `tebunko のインデックスの zip ではない、または壊れています（形式が違います）。` ／ `tebunko のインデックスの zip ではない、または壊れています（形式の版が読めません）。` |
| 同上 | 古い形式・新しい版の zip | `古い形式のインデックスの zip のため、読み込めません。<古い形式の文言>` ／ `新しい版の tebunko で作られたインデックスのため、この版では読み込めません。` |
| 同上 | 大きさ・数の上限を超える（悪用を防ぐ） | `目録（<名前>）が大きすぎます。` ／ `zip のエントリーの数が多すぎます。` ／ `<名前> が大きすぎます。` ／ `インデックスの合計の大きさが大きすぎます。` |
| 同上 | 目録の内容がおかしい | `目録のインデックス名が使えません（<名前>）` ／ `目録に、許されない場所のエントリーがあります: <名前>` ／ `目録に同じパスが 2 つあります: <パス>` ／ `目録のファイルの大きさが読めません: <パス>` ／ `目録のファイルの SHA-256 がありません: <パス>` ／ `目録に <項目> がありません。` |
| 同上 | zip の中身と目録が合わない | `zip の中に同じ名前のエントリーが 2 つあります: <名前>` ／ `目録に無いエントリーが zip にあります: <名前>` ／ `目録にあるのに zip に無いエントリーがあります: <名前>` ／ `エントリー「<名前>」が目録の大きさより大きく展開されました。` ／ `エントリー「<名前>」の大きさか内容が目録と違います。` |
| 同上 | 展開先が置き場の外・途中にリンクがある | `置き場の外か、途中にリンクがあるため、展開できません: <パス>` |

## インデックスの読み込み（インポート）の実行

| 表示場所 | 条件 | 文言 |
|---|---|---|
| エラーの帯・ダイアログ | インデックス作成の実行中に読み込もうとした | `更新中はインポートできません。更新が終わってからやり直してください。` |
| 同上 | zip の取り込み一覧・インデックスのファイルを読めない | `ingest_status.tsv を読み込めません（<原因>）` ／ `インデックスのファイル「<名前>」を読み込めません（<原因>）。エクスポートした側で更新し直してから、もう一度エクスポートしてください。` |
| 同上 | 名前・元のフォルダの指定が使えない | `「<名前>」は、ほかのインデックスが使っています。別の名前を付けてください。` ／ `元のフォルダを指定してください。` ／ `「<パス>」のインデックス [<名前>] が既にあります。` |
| 同上 | 元のフォルダが、ほかのインデックスの中・外と重なる | `「<パス>」は、インデックス [<名前>]（<パス>）の中のフォルダです。` ／ `「<パス>」の中には、インデックス [<名前>]（<パス>）があります。` ／ `同じファイルが二重にインデックスに入るため、登録できません。検索する範囲を絞るときは［検索］の検索対象で外してください。` ／ `同じファイルが二重にインデックスに入るため、登録できません。まとめるときは、先に [<名前>] を削除してください。` |
| 同上 | 保存先の空き容量が足りない | `保存先の空き容量が足りません（必要 約 <N> MB）。` |
| 同上 | 目録を書けなかった | `インデックスの目録を書けません（新しい版の tebunko で作られたワークスペースの可能性があります）。` |
| 同上 | 置き場の外・途中にリンクがあり、入れ替え・後片付けができない | `置き場の外か、途中にリンクがあるため、インデックスを入れ替えられません: <パス>` ／ `置き場の外か、途中にリンクがあるため、入れ替えを戻せません: <パス>` ／ `置き場の外か、途中にリンクがあるため、作業フォルダを消せません: <パス>` |

## インデックスの名前の変更・削除

| 表示場所 | 条件 | 文言 |
|---|---|---|
| エラーの帯 | 名前の変更で、元の・新しい名前が使えない | `元のインデックス名が使えないため、名前を変えられません: <名前>` ／ `新しいインデックス名が使えないため、名前を変えられません: <名前>` |
| 同上 | 名前の変更で、置き場の外・途中にリンクがある・同じ名前のフォルダが既にある | `置き場の外か、途中にリンクがあるため、名前を変えられません: <パス>` ／ `「<名前>」のフォルダが既にあるため、名前を変えられません: <パス>` |
| 同上 | 削除で、名前が使えない・置き場の外・途中にリンクがある | `インデックス名が使えないため、削除できません: <名前>` ／ `置き場の外か、途中にリンクがあるため、削除できませんでした: <パス>` |

## ワークスペースの変更・設定の保存と読み込み

| 表示場所 | 条件 | 文言 |
|---|---|---|
| ［設定］のエラー・起動のエラー | 環境変数 `TEBUNKO_DEFAULT_WORKSPACE` の指定がフォルダの絶対パスでない | `TEBUNKO_DEFAULT_WORKSPACE はフォルダまで含めた絶対パスで指定してください: <値>` |
| 起動のエラー | 壊れた `setting.config` を退避できなかった（[壊れた設定ファイルの退避](../structure/settings-file.md#壊れた設定ファイルの退避)） | `<設定ファイル名> が壊れているため退避しようとしましたが、移せませんでした。tebunko を使っているほかのプログラム（ウイルス対策ソフトなど）を確かめてください。（<原因>）` |
| ［設定］の検索結果の件数の上限の欄 | 範囲外の値 | `検索結果の件数の上限は、0（制限なし）か <最小>～<最大> で指定してください: <値>` |
| 起動・［設定］のエラー | ワークスペースの場所に接続できない・確かめられない（[ネットワークにあるとき](network.md)） | `ワークスペースに接続できません：<パス>` ／ `ワークスペースを確かめられません：<パス>` |
| ［設定］でワークスペースを変えたとき | 移し先に、すでにファイルがある | `「<パス>」には、すでに <名前> があります。空のフォルダを選んでください。` |
| 同上 | 中身を移せなかった（ほかのアプリが開いている等） | `ワークスペースの中身を「<パス>」へ移せませんでした（<原因>）。ファイルを開いているアプリを閉じてから、もう一度変えてください。<後片付けの結果>` |
| フォルダを選ぶダイアログ | ダイアログがエラーを返した | `フォルダ選択のダイアログがエラーを返しました（0x<コード>）` |
