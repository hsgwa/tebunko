# 画面に出すメッセージ：検索と検索結果

扱うこと: ［検索］タブ（吹き出し・件数・ステータス・結果の出力）と、検索結果から元のファイルを開く・コピーするときの文言と条件。入口と決まり: [画面に出すメッセージの一覧](messages.md)。

## 検索

| 表示場所 | 条件 | 文言 |
|---|---|---|
| 吹き出し（［正規表現］の下） | 正規表現オンで不正なワード | `正規表現が正しくありません`（理由は書かない。検索は始めず、［検索］は押せない） |
| 吹き出し（種類のチップの下） | 種類のチップを 1 つも選んでいない | `種類を 1 つ以上選んでください`（［検索］を押したとき。［検索］は押せるまま） |
| 件数（No.5） | 本文インデックスを数えている / 検索中 / 完了 / 絞り込み中 | `検索対象のファイルを確認しています…（N 件）` / `検索中…　該当 K 件` / `一致 N 件（M ファイル）・X 秒` / `一致 N 件中 K 件を表示` |
| 件数（No.5） | 上限を超えて数えている / 数え終えた | `検索中…　該当 10,000 件以上（総数を数えています：K 件）` / `全 N 件中 H 件を表示（F ファイル）・X 秒`（数えている間に中止したときは `該当 H 件以上（総数は数えていません）（F ファイル）`。`getSearchCountingText`・`getSearchFinishSummaryText`） |
| 件数（No.5） | 0 件 | 結果欄の真ん中に `一致する結果はありません`（`getNoHitText`。`NoHitText`。検索を始めたとき・結果を消したときに隠す）。ステータスバーに `検索しました：<ワード> 0 件`（既定から変えた検索条件があれば `　条件：…` を添える） |
| 結果の表の「続き」の行 | 1 つのファイルのヒットが 1,000 件を超える（開いたファイルの行の末尾） | `続きの 1,000 件を表示（残り 99,000 件）`（`getMoreRowsText`。残りが 1,000 件より少ないときは、その件数） |
| 件数（No.5） | 選んだ種類に合うファイルが無い | `種類（Word・テキスト）に合うファイルがありません。`（種類を絞っていないときは `検索できるファイルがありません。`） |
| 件数（No.5） | 検索対象に本文インデックスが無い | `検索対象のインデックスがありません。先にインデックスを作成してください。` |
| ステータス | 検索ワードが空 / 検索対象にチェックが無い | `検索ワードを入力してください。` / `検索するフォルダに、左の「検索対象」でチェックを付けてください。` |
| ステータス | 検索が終わった | `検索しました：<ワード> N 件`。既定から変えた検索条件があれば `検索しました：<ワード> N 件　条件：<条件>` |
| ステータス | 正規表現の照合が終わらない（1 行 5 秒超） | `検索できませんでした：正規表現の照合に時間がかかりすぎるため、検索を中止しました。正規表現を見直してください。`（No.5 は `検索できませんでした`） |
| ステータス | 中止した / 上限を超えて数え終えた | `中止しました（N 件まで表示）` / `検索しました：<ワード>（全 N 件のうち、先頭の L 件を表示）。` に続けて既定から変えた検索条件の `　条件：<条件>`。上限を超えて数えている間に中止したとき・正規表現の照合が時間切れになったときは、総数を数えていないことを書く（`getSearchFinishStatusText`）。 |
| ステータス | 見つからない検索対象フォルダがあった / 読めないインデックスのファイルがあった / 更新中に検索した | 上の文に続けて `見つからない検索対象フォルダ：<パス>` / `読めなかったインデックスのファイル：N 件`（0 件なら出さない） / `更新中のため、更新の途中のインデックスを検索しています。` を添える |

## 元のファイルを開く・コピーする

| 表示場所 | 条件 | 文言 |
|---|---|---|
| ダイアログ（［ファイルの一覧］の行のダブルクリックでも同じ形） | 元のフォルダに接続できない（[ネットワークにあるとき](network.md)） | 見出し `<ファイル名> を開けません`。知らせ `✗ 元のフォルダに接続できません`（`<元のフォルダ>`）＋ `→ ネットワーク・VPN の接続を確かめてから、もう一度開いてください`。選択肢は［フォルダを選ぶ］（選べば見つからないときと同じ流れに進む）と［閉じる］ |
| ステータス | 元のフォルダに接続できない / 元のファイルを確かめている（［ファイルの一覧］の行のダブルクリックも同じ。見つからないときの文言とは別） | `元のフォルダに接続できません：<パス>`（検索結果からは `<元のフォルダ>`）/ `元のファイルを確かめています…：<パス>` |
| 確認 | 元のファイルが無い・元の場所が分からない | フォルダを選ぶかの確認（[元のファイルが見つからないとき（元のフォルダを設定する）](open-file.md#元のファイルが見つからないとき元のフォルダを設定する) のメッセージ） |
| 確認 | もらったインデックス（設定に無い名前）の元のフォルダを、開く前に確かめる | `<ファイル名> の元のフォルダを確かめてください`、［フォルダを選ぶ］［このフォルダを使う］（ローカルのドライブと分からないとき（共有フォルダなど）は、サインイン情報が送られることがある旨を添える。[もらったインデックスの元のフォルダを確かめる](open-file.md#もらったインデックスの元のフォルダを確かめる)） |
| ステータス | 上の確認でキャンセルした | `開くのをやめました` |
| ステータス | もらったインデックスのマクロを持てる形式を、読み取り専用で開いた / 読み取り専用で開けず開かなかった | `読み取り専用で開きました：<パス>（もらったインデックスのため、マクロを持てる形式は読み取り専用で開きます）` / `もらったインデックスのファイルは読み取り専用で開けなかったため、開きませんでした。［ファイルのパスをコピー］で場所を調べ、確かめてから開いてください：<パス>`（[もらったインデックスのマクロを持てる形式](open-file.md#もらったインデックスのマクロを持てる形式)） |
| ステータス | 元のファイルが無い（フォルダを選ばなかった） | `元のファイルが見つかりません：<パス>` |
| ステータス | 選んだフォルダ・別の書き方のパスで見つかった | `インデックス [<名前>] の元のフォルダを <フォルダ> に変えました`（続けて開いた結果で上書きされる） |
| ステータス | 元のファイルを開いた | `開きました：<パス>` / `読み取り専用で開きました：<パス>` / `新規で開きました：<パス>`（Excel で該当セルへ移動できなかったときは `（該当セルへの移動はできませんでした）` を付ける。テキスト・PDF などの［新規で開く］はコピーを開き、`コピーを新規で開きました（コピー：<コピーのパス>。保存してもこのコピーに書かれ、元のファイルは変わりません）：<パス>` と出す。[元のファイルを開く](open-file.md)） |
| ステータス | 行・セル・パスをコピーした | `N 行をコピーしました（Excel に貼り付けると、元の列の位置に並びます）` / `セルの値をコピーしました：<値>` / `N 個のセルをコピーしました（Excel に貼り付けると、元の位置に並びます）` / `パスをコピーしました：<パス>` |

## 結果の出力

| 表示場所 | 条件 | 文言 |
|---|---|---|
| ステータス | まだ検索していないのに出力しようとした | `先に検索してください。` |
| ステータス・帯 | 結果を出力した / 書き込めない（書き込めないときは検索画面の上の帯） | `<名前> に N 件を出力しました（出力したファイルを開きます）`（絞り込み中は `絞り込み後の N 件を <名前> に出力しました`。ファイルを開けなければ `<名前> に N 件を出力しました。ファイルを開けなかったため、<パス> を開いてください`） / `<名前> に書き込めません。開いているアプリを閉じてから、もう一度出力してください。` / `<名前> に書き込む権限がありません（読み取り専用など）。<パス> を確かめてから、もう一度出力してください。`（[結果をファイルに出力](search-tab.md#結果をファイルに出力)） |
| ステータス・ボタン | 結果を出力している間 | ボタン `出力を中止`（ふだんは `出力`。この間 ▾ は隠れる）。検索の途中で押したとき `検索が終わってから出力します…`、書き込み中 `検索結果を出力中…（N 件）`、中止 `出力を中止しました。出力先のファイルは変えていません。`、失敗 `検索結果を出力できませんでした：<理由>` |
| ステータス | 上限を超えた分も出力した | `表に入らなかった分も含めて、全 N 件を <名前> に出力しました`（絞り込み中は `…含めて、絞り込み後の N 件を…`。並べ替え中は末尾に `（件数が多いため、並べ替えは当てずに検索の順で出力しました）`） / 表の分だけのとき `表に出ている N 件だけを <名前> に出力しました（<理由>）`（理由: `総数を数える時間が切れたため、残りは出力していません` / `表に入らない分を一時ファイルに書けなかったため、残りは出力していません` / `検索を途中で止めたため、残りは出力していません`）。Excel ブックの行の上限を超えたときは `（N 件は Excel の行の上限を超えたため書いていません。全件は CSV か TSV で出力してください）`、長すぎるセルを切ったときは `（N 個のセルは長すぎるため、途中で切りました）` を添える |
