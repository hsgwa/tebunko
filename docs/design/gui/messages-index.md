# 画面に出すメッセージ：インデックス管理

扱うこと: ［インデックス管理］タブ（一覧・詳細・追加・編集・削除・更新の確認・取り込み対象の拡張子）が出す文言と条件。扱わないこと: インデックスの書き出し・読み込み・名前変更・ワークスペースの変更で断られたときのエラー（[messages-index-ops.md](messages-index-ops.md)）。入口と決まり: [画面に出すメッセージの一覧](messages.md)。

## 名前とフォルダパスの編集のエラー

詳細の名前・フォルダパスの欄・［＋ フォルダを追加］で、入力を確かめた結果（`getIndexDetailEditDecision` / `testIndexEditInput` / `testIndexName`）。欄の下の赤字（`IndexDetailEditError`）に出す。

| 条件 | メッセージ |
|---|---|
| フォルダが空 | `元のフォルダを指定してください。` |
| ほかのインデックスと同じフォルダ | `「<パス>」のインデックス [<名前>] が既にあります。` |
| ほかのインデックスのフォルダの中（`testFolderUnder`） | `「<パス>」は、インデックス [<名前>]（<そのパス>）の中のフォルダです。同じファイルが二重にインデックスに入るため、登録できません。検索する範囲を絞るときは［検索］の検索対象で外してください。` |
| 中にほかのインデックスのフォルダがある | `「<パス>」の中には、インデックス [<名前>]（<そのパス>）があります。同じファイルが二重にインデックスに入るため、登録できません。まとめるときは、先に [<名前>] を削除してください。` |
| 名前が空 | `名前を入力してください。` |
| 名前の前後に空白 | `名前の前後に空白は使えません。` |
| 名前が 255 文字超 | `名前が長すぎます（255 文字まで）。` |
| 名前にファイル名で使えない文字 | `名前に使えない文字が含まれています（\ / : * ? " < > \| と制御文字）。` |
| 名前の末尾が `.` | `名前の最後に . は使えません。` |
| 名前が Windows の予約語（`CON` `PRN` `AUX` `NUL` `COM1`〜`COM9` `LPT1`〜`LPT9`） | `「<名前>」は Windows で使えない名前です。` |
| ほかのインデックスと同じ名前（大文字・小文字を区別しない） | `「<名前>」は、ほかのインデックスが使っています。別の名前を付けてください。` |
| 設定から外したインデックスが残っている名前を、前回と違うフォルダに付ける | `「<名前>」は、設定から外したインデックスが残っているため、このフォルダには使えません。別の名前を付けるか、［すべて更新］の確認に「削除予定」として出るインデックスを削除してから付けてください。` |
| 取り込み一覧に行が無く、作業フォルダの置き場にだけ同じ名前のインデックスがある（前回のフォルダが分からず、［すべて更新］の確認に「削除予定」として出ない） | `「<名前>」は、作業フォルダに同じ名前のインデックスがあるため使えません。別の名前を付けてください。` |
