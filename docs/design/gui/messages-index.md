# 画面に出すメッセージ：インデックス管理

扱うこと: ［インデックス管理］タブ（一覧・詳細・追加・編集・削除・更新の確認・取り込み対象の拡張子）が出す文言と条件。扱わないこと: インデックスの書き出し・読み込み・名前変更・ワークスペースの変更で断られたときのエラー（[messages-index-ops.md](messages-index-ops.md)）。入口と決まり: [画面に出すメッセージの一覧](messages.md)。

## インデックス管理

| 表示場所 | 条件 | 文言 |
|---|---|---|
| 一覧の中 | インデックスが 1 件も無い | `フォルダを追加してください` ／ `検索したいフォルダを追加すると、ここに表示されます。` |
| 一覧の「フォルダの状態」 | フォルダがある / 無い / 調べている | `フォルダがあります`（緑のチェックのアイコン付き） / `フォルダが見つかりません`（赤の × のアイコン付き） / `… フォルダを確認しています` |
| 保存先の行（一覧の上）・インデックス更新の確認 | いつも / 保存先が共有のとき | 見出し `インデックスの保存先` とパス（注意はⓘ・パスのツールチップと確認のカードの中: `インデックスには本文がそのまま入り、元のアクセス権は引き継がれません。保存先は設定画面で変更可能です。`）/ 警告の帯 `共有フォルダを選択しています。他のユーザーが閲覧できる可能性があります。`（`getSharedFolderWarningText`。`getIndexLocationView` から。［設定］のワークスペース変更の確認でも、選んだ場所が共有のとき warn の行（先頭）に同じ文を出す: `newWorkspaceConfirm` の `isNetwork`） |
| ステータス（確認では確認の中） | 保存先の［フォルダを開く］で開けない | `保存先のフォルダを確かめています…：<パス>`（共有のとき確かめる間）/ `保存先のフォルダはまだありません（インデックスを作ると作られます）：<パス>` / `保存先のフォルダに接続できません：<パス>` / `保存先のフォルダを開けません：<パス>（<理由>）`（`getIndexLocationOpenStatus`） |
| 一覧の「ステータス」 | 本文の更新の状態（バッジの文言） | `未作成` / `更新中` / `要更新` / `エラー` / `最新`（[一覧の列](index-tab.md#一覧の列)） |
| 詳細（何も選んでいない・複数を選んだ） | 何も選んでいない / 2 件以上にチェックを付けた | 見出し `インデックスの状態` と案内 `一覧で 1 件選ぶと、ここに詳細を表示します。` ／ 見出し `N 件を選択中` と案内 `1 件だけ選ぶと、ここに詳細を表示します。`（`getIndexDetailView`） |
| ダイアログ（取り込んだファイルの一覧） | 開いている / 読み込んでいる間 / 読み込めなかった / 一覧が 0 件 / 失敗のみで 0 件 | 題 `<インデックス名> のファイル`（`getIndexFilesDialogTitle`）。見出し `ファイル N 件（うち失敗 M 件・未取り込み K 件）`（`getIndexFilesHeading`）／ `ファイルの一覧を読み込んでいます…`（`getIndexFilesLoadingText`）／ `ファイルの一覧を読み込めませんでした`（`getIndexFilesLoadFailedText`）／ `まだ取り込んだファイルはありません`。表の中央に `失敗したファイルはありません。`（`getIndexFilesEmptyNotice`）。下の注記 `ダブルクリックでファイルの場所を開きます` |
| 詳細の名前・フォルダパスの欄 | 入力に誤りがある | [名前とフォルダパスの編集](index-tab.md#名前とフォルダパスの編集) のとおり（欄の下に赤字） |
| ステータス | インデックスを追加した | `インデックス [<名前>] を追加しました。［すべて更新］を押すと中身を更新します` |
| ステータス | 追加したがフォルダが無い | `インデックス [<名前>] を追加しましたが、フォルダが見つかりません：<パス>` |
| ステータス | 同じフォルダのインデックスがある | `「<パス>」のインデックス [<名前>] は既にあります` |
| ステータス | インデックスを編集した | `インデックスを変更しました（名前 [<旧>] → [<新>] / 場所 <旧> → <新>）` |
| ステータス | インデックスを削除している（別スレッド） | `インデックス [<名前>] を削除しています…（件数によっては少し時間がかかります）` |
| ステータス | インデックスを削除した | `インデックス [<名前>] を削除しました` |
| ステータスと帯 | 削除に失敗した（1 件） | `インデックス [<名前>] の削除に失敗しました：<メッセージ>`（［インデックス管理］の上の帯にも同じ文を出す。次の削除が成功すると消える） |
| 確認 | インデックスの削除 | [［インデックス管理］タブ](index-tab.md) No.4 のとおり |
| 確認 | インデックス作成の内容 | [インデックス作成の確認ダイアログ](indexing-run.md#インデックス更新の確認ダイアログ) のとおり（インデックスごとの更新の対象の件数） |
| 確認（インデックス更新の確認ダイアログ） | 取り込む行の「取り込み対象の拡張子」列 | 何も外していない `すべて取り込み`（ToolTip `実行・登録になる 15 個（.bat・.ps1 など）を含みます。取り込むだけで、実行はされません。`）／外している `対象外あり`。ボタン［変更…］ |
| ダイアログ（取り込み対象の拡張子） | 開いたとき | 題 `取り込み対象の拡張子 - 〈インデックス名〉`。注 `チェックを外した拡張子は対象外になり、そのファイルは、次のインデックス作成で、このインデックス（〈名前〉）から外します。` に、件数の出どころで `件数は、前回の更新（〈日時〉）で数えた結果です。`／`件数は、いま数えた結果です。`／`まだ件数がありません。更新すると、件数が出ます。` のどれか（Excel・Word・PowerPoint が選べないという文は無い）。上の要約 `取り込み対象 N 件（対象外 M 件）`（件数が無いとき `更新すると、件数が出ます`）。種類の見出し `Excel`・`Word`・`PowerPoint`・`PDF`・`テキスト`。絞り込みのチェック `取り込み対象のみ表示` |
| 確認（インデックス更新の確認ダイアログ） | 対象外にした拡張子のファイルを外す件数が 1 件以上 | 合計の下に `対象外にした拡張子のファイル N 件を、インデックスから外します`（N は 3 桁区切り） |
| 確認（インデックス更新の確認ダイアログ） | どの行も拡張子を外していない | 説明に `各インデックスの［変更…］で、取り込むテキストの拡張子を選べます。拡張子ごとの件数は、いま数えた結果です。` |
| 帯（インデックス作成） | 確認で取り込む拡張子を変えて始め直した、数えの間 | `数えています…`（数えたファイル数があれば `数えています…（1,240 ファイル）`） |
| 警告 | 更新中に追加・編集・削除しようとした | `更新中はインデックスを<追加／編集／削除>できません。更新が終わるまでお待ちください（［中止］で止められます）。` |
| 警告 | 前のインデックスの削除・名前の変更中に操作しようとした | `前のインデックスの削除・名前の変更が終わるまでお待ちください。` |
| ステータス | 保存した（更新を始めるときの保存では出さない） | `インデックス一覧を保存しました（H:mm）` |
| ステータス | インデックス一覧がほかで変更された（[画面での読み書き](../structure/settings-file.md#画面での読み書き)） | `インデックス一覧がほかで変更されたため、読み直しました` |
