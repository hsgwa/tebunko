# ［9 プロセス停止］タブ

インデックス作成を中断したときなどに残った Excel・Word・PowerPoint のプロセスを一覧し、終了するタブ。

![［9 プロセス停止］タブ](../../images/画面_プロセス停止タブ.drawio.png)

| No. | 部品 | 仕様 |
|---|---|---|
| 1 | プロセスの表 | 見出しは `残っている Office のプロセス`、その下に `インデックス作成を中断したときなどに残った Excel・Word・PowerPoint のプロセスを終了します。`。実行中の Excel・Word・PowerPoint を一覧する（[プロセスの表](#プロセスの表)）。複数選択できる |
| 2 | ［更新］ | 一覧を取り直す。F5 でも同じ。表の下に `N 件（バックグラウンド X 件・画面に表示中 Y 件） ・ H:mm:ss 時点` を表示する（0 件なら `実行中の Excel・Word・PowerPoint はありません。（H:mm:ss 時点）`） |
| 3 | 説明 | `バックグラウンド：画面にウィンドウが無いプロセス（取り込みで起動したものなど）。` `画面に表示中のプロセスを終了すると、保存していない内容は失われます。` |
| 4 | ［バックグラウンドのみ終了（N 件）］ | 主ボタン。バックグラウンドのプロセスをすべて終了する。0 件なら無効 |
| 5 | ［選択したプロセスを終了］ | 表で選択したプロセスを終了する。未選択なら無効 |
| 6 | ［すべて終了］ | 一覧のすべてを終了する。0 件なら無効。赤枠で表示し、誤操作に注意を促す |
| 7 | タブ見出し | バックグラウンドのプロセスがあるとき `⚠` を付ける（[タブ見出しの ⚠](#タブ見出しの-)） |

## プロセスの表

| 列 | 内容 |
|---|---|
| 種類 | `Excel` / `Word` / `PowerPoint`（プロセス名 `EXCEL` / `WINWORD` / `POWERPNT`） |
| PID | プロセス ID |
| 起動時刻 | 当日なら `H:mm`、それ以前は `M/d H:mm`。取得できなければ空欄 |
| メモリ | ワーキングセット（MB） |
| ウィンドウ | ウィンドウのタイトル。無ければ `（なし）` |

- 一覧とバックグラウンドの判定は `shared/office/office_process.ps1` の `getOfficeProcesses`、終了は `stopOfficeProcesses` で行う（[実装構成](implementation.md#実装構成)）。「バックグラウンド」は `MainWindowHandle` が 0 のものをさす。列としては表示せず、並び順・［バックグラウンドのみ終了］・タブ見出しの `⚠` に使う（画面上では「ウィンドウ」列が `（なし）` かどうかで分かる）。
- 並び順はバックグラウンドを先に、次に起動時刻の古い順とする。
- タブを開いたとき・［更新］・終了操作の前後に取り直す。タブを表示している間は 5 秒ごとに自動で取り直す。自動の取り直しは画面の裏の仕事のスレッド（`startJob`）で行い、画面のスレッドでプロセスを調べない（前の取り直しが終わっていなければ重ねない）。［更新］などの操作での取り直しは、すぐ一覧が要るため画面のスレッドで行う。

## 終了の確認

終了は `Stop-Process -Force`（保存確認なし）で行うため、必ず確認ダイアログ（[確認ダイアログ](common.md#確認ダイアログshowconfirm)）を出す。ボタンは［終了する］。

| 操作 | 見出しと結果 | ボタン |
|---|---|---|
| バックグラウンドのみ | `バックグラウンドの Office を N 件終了しますか？` ＋ `✓ 画面に出ているファイルはありません`（`Excel 2 件・Word 1 件`）／ `→ 残ったまま動いていたものを片付けます`（`次のインデックス作成で作り直されます`） | ［終了する］が既定 |
| 選択・すべて（画面に表示中を含まない） | 同上 | ［終了する］が既定 |
| 選択・すべて（画面に表示中を含む） | `開いたままの Office を N 件、強制的に終了しますか？` ＋ `✗ 保存していない内容は失われます`（`画面に出ているもの：Excel 1 件・PowerPoint 1 件`）／ `✓ ファイル自体は消えません`（`保存し忘れがないか、先に画面で確かめてください`） | 赤い［終了する］。**［キャンセル］が既定** |
| インデックス作成が実行中（3.3 の「インデックス作成中」） | 上の結果に `✗ いま取り込み中のファイルは失敗あつかいになります`（`インデックス作成が終わってから終了するのが安全です`）を足す | 赤い［終了する］。［キャンセル］が既定 |

- 終了後はステータスに `N 個のプロセスを終了しました。` と表示し、一覧を取り直す。
- 終了できなかったプロセス（権限不足など）があれば、`PID <N> を終了できませんでした：<理由>` と表示する。

## タブ見出しの ⚠

- バックグラウンドのプロセスが 1 件以上あり、かつインデックス作成が実行中（3.3 の「インデックス作成中」）でないとき、`⚠ 9 プロセス停止` と表示する。
- 判定は起動時と、ウィンドウがアクティブになったときに行う。アクティブになったときの数え上げは、画面の裏の仕事のスレッド（`startJob`）で行い、数が分かったら印を付け直す。
