# 画面に出すメッセージ：インデックス作成の実行

扱うこと: インデックス作成（［すべて更新］・行の［更新］）の帯・確認ダイアログ・中止・終わりの文言と条件。扱わないこと: 帯の形・色・ボタンの置き方と動き（[インデックス作成の実行](indexing-run.md)）、ログ欄・ファイルのログの文言（[エラーの一覧](../indexing/errors.md)）。入口と決まり: [画面に出すメッセージの一覧](messages.md)。

## 帯とバー

| 表示場所 | 条件 | 文言 |
|---|---|---|
| 帯（青） | 更新中 | `インデックスを更新しています（N / M 件）`（失敗があれば `・失敗 K 件`）。右に `残り約 N 分` |
| 帯（黄） | 中断（残りがあるまま画面を開いたときも出す） | `更新を中断しました（残り N 件）` |
| 帯（緑。注意が要る終わり方は橙） | 終わった | 下の「終わったとき」の文言 |
| タスクバーのバー・ステータス | インデックス作成の確認待ち（バーは黄色） | `確認` / `更新する内容を確認してください`、`更新するインデックスの一覧を表示しています。` |
| 一覧の下 | 始める前にワークスペースに届かない（ネットワークのとき。[ネットワーク](network.md#ワークスペースがネットワークにあるとき)） | `ワークスペースに接続できません：<パス>`（始めない） |

## 確認ダイアログの合計

| 条件 | 文言 |
|---|---|
| 更新するものがある | `更新対象: N フォルダ / M ファイル（最新のフォルダは更新しません）` |
| 更新が必要なファイルが無い | `更新が必要なファイルはありません（すべて最新です）。` |
| 同じで、クラウドにだけあるファイルが残る（チェックを付ければ、その件数を足した `更新対象` にする） | `更新が必要なファイルはありません。クラウドにだけあるファイル N 件は、ダウンロードせずに残します。` |
| 注意書き（上の「無い」場合に添える） | `更新日時が変わらないまま中身が変わったファイルは、更新の対象になりません。そのインデックスを一から作り直すときは、［削除］してから追加し直してください。` |

取り込み対象の拡張子の列と対象外の件数の文は[画面に出すメッセージ：インデックス管理](messages-index.md#インデックス管理)にある。

## 中止

| 表示場所 | 条件 | 文言 |
|---|---|---|
| 確認ダイアログ | 帯の［中止］を押した | 見出し `インデックスの更新を中止しますか？`、補足 `更新したところまでは残ります。あとで続きから再開できます。`、ボタン［中止する］（既定は［キャンセル］） |
| ステータス・待つ間のダイアログ | 中止して終わりを待つ間 | `中止しています…（取り込みを止めて、取り込めた分をまとめています）` |

## 終わったとき

終了コードに応じて、判断層（`getIndexingEndText`。`indexing_view.ps1`）が見出しと説明を決める。

| 終了コード・条件（上から見て最初に当たるもの） | 文言 |
|---|---|
| 0・更新した（成功＋失敗）が 1 件以上 | `更新が終わりました（成功 N 件 / 失敗 M 件）`。失敗があれば説明に `失敗したファイルと原因は「ファイルの一覧」（失敗のみ）で確認できます。` を加える |
| 0・どちらも 0 件で、クラウドにだけあるため残したファイルがある | `クラウドにだけあるファイル N 件は、ダウンロードせずに残しました（次のインデックス作成でも確かめます）。`（残したファイルがあるときは、上の最初の説明にも同じ文を加える） |
| 0・どちらも 0 件 | `更新が必要なファイルはありませんでした` |
| 2・確認で取りやめた | `更新を取りやめました`、`更新したファイルはありません。［すべて更新］を押すと、もう一度確認できます。` |
| 2・中止した | `更新を中止しました（成功 N 件 / 失敗 M 件 / 残り K 件）`、`次回は続きから再開できます。` |
| 1・続けられないエラー（クロール対象フォルダが無い など） | `インデックスを更新できませんでした` とそのメッセージ（同じ内容をエラーのダイアログでも出す） |
