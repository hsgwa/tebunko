# インデックスを作る

［1 インデックス管理］タブでは、検索したいフォルダを登録し、そのフォルダの Office ファイルから文字を取り出して**インデックス**を作ります。検索はこのインデックスを使います。

![［1 インデックス管理］タブ](../images/readme_index.png)

## フォルダを登録する

1. ［追加…］を押します。
2. 「元のフォルダ（Office ファイルのある場所）」に、フォルダを指定します。［参照…］で選ぶほか、パスの入力・貼り付け、フォルダのドラッグ＆ドロップでも指定できます。
3. 「インデックス名」は、フォルダ名から自動で入ります。検索対象の一覧と検索結果にこの名前が出ます。`\ / : * ? " < > |` は使えません。
4. ［OK］を押します。

一覧に、エクスプローラーからフォルダを直接ドラッグ＆ドロップしても追加できます。ネットワークドライブや `\\server\share` の形の共有フォルダも登録できます。

!!! note "登録できないフォルダ"
    すでに登録したフォルダと同じフォルダや、その中（または外側）のフォルダは登録できません。1 つのファイルが 2 つのインデックスに入らないようにするためです。

## 一覧の見方

| 列 | 内容 |
|---|---|
| 作成 | チェックを付けたインデックスだけを取り込みます |
| インデックス名 | 検索結果に出る名前 |
| 元のフォルダ | Office ファイルのある場所 |
| フォルダの状態 | フォルダが見つかるか |
| ファイル | 取り込んだファイルの数と、その内訳 |
| 最終取り込み | 最後に取り込んだ日時 |

## インデックスを作る

1. 取り込みたいインデックスの［作成］にチェックを付けます。
2. ［インデックス作成を開始］を押します。
3. 「インデックス作成の確認」に、インデックスごとの取り込み対象の数と内訳が出ます。［OK］で取り込みを始めます。取り込むものが無いときは［閉じる］だけが出ます。

取り込むのは、**新しいファイルと、前回から変わったファイルだけ**です（更新日時とサイズで判定します）。元のフォルダからファイルが無くなったときは、そのファイルのインデックスも消します。

進み具合は「インデックス作成中… N / M 件（失敗 K 件）」と残り時間で表示します。目安は、Office ファイル 300 件（ほとんどが Excel）で約 3 分です。大きなファイルが多いと、そのぶん時間がかかります。

### 作成中にできること・できないこと

- **検索はできます。** 取り込みが終わったフォルダから順に検索結果に出ます。
- **画面を閉じると止まります。** インデックス作成は tebunko の画面の中で動いているためです。閉じようとすると確認が出るので、［インデックス作成を止めて閉じる］か［閉じない］を選びます。止めても、次は続きから再開します。
- ワークスペースは変えられません（[設定](settings.md)）。

## 中止する・再開する

［中止］を押し、確認で［中止する］を選ぶと、今のファイルの取り込みが終わったところで止まります。次に始めるときは、ボタンが［続きから再開（残り N 件）］になり、残りから取り込みます。

終わったら［ログを開く］で、取り込みの経過を確かめられます。

## 取り込みに失敗したファイルがあるとき

パスワード付きのファイルなど、取り込めなかったファイルがあると、タブの見出しに ⚠ が付き、「⚠ 取り込みに失敗したファイル N 件」の一覧（ファイル・失敗の原因・日時）が出ます。行をダブルクリックすると、そのファイルの場所が開きます。

失敗したファイルは、更新されない限り次回からは取り込みません。もう一度試すときは、「インデックス作成の確認」で「前回取り込みに失敗し、その後更新されていないファイル N 件も再取り込みする」にチェックを付けます。

失敗の原因ごとの対処は [困ったとき](troubleshooting.md#取り込みに失敗したファイルがある) を見てください。

## 名前や場所を変える（［編集…］）

一覧で選んで［編集…］を押すと、インデックス名と元のフォルダを変えられます。元のフォルダを別の場所に移したときは、ここで新しい場所を指定するだけで済みます。インデックスを作り直す必要はありません。

## 削除する（［削除］）

一覧で選んで［削除］（または Delete キー）を押し、確認で［削除する］を選ぶと、一覧から外し、そのインデックス（tebunko が作ったデータ）も消します。**元のフォルダとファイルはそのまま残ります。**
