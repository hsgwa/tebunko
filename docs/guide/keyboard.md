# キーボード操作

| キー | 対象 | 動作 |
|---|---|---|
| Enter | 検索ワード・対象ファイルの入力欄 | 検索を実行する |
| Esc | 全体 | 検索中の場合、検索を中止する（ウィンドウは閉じない） |
| Ctrl+F | 全体 | ［2 検索］に切り替え、検索ワードの入力欄を選択する |
| Ctrl+Shift+F | ［2 検索］ | 「結果の中から探す」の入力欄に移動する |
| Enter | 検索結果 | 元のファイルの該当箇所を開く。見出しの行では、そのファイルの該当行の表示・非表示を切り替える |
| Ctrl+C | 検索結果 | 選択した行をコピーする。見出しの行を選択している場合は、そのファイルのすべての該当行 |
| Ctrl+C | プレビュー | 選択したセルの値をコピーする |
| Space | 検索対象のツリー | 選択中の項目のチェックを切り替える |
| F5 | 全体 | ［9 プロセス停止］ではプロセスの一覧を、その他のタブではインデックスの状態と検索対象のツリーを再読み込みする |
| Ctrl+Tab / Ctrl+Shift+Tab | 全体 | タブを切り替える |
| Delete | インデックスの一覧 | 選択したインデックスを削除する（確認あり） |

インデックス作成の開始とプロセスの終了は、影響が大きいため、ショートカットキーを割り当てていません。

詳細は設計書の [画面の共通仕様](../design/gui/common.md#キーボード操作) を参照してください。
