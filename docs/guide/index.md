# はじめに

tebunko は、フォルダにたまった Excel・Word・PowerPoint を、ファイルの中の文字で検索する Windows 用のツールです。先にファイルから文字を取り出して検索用の索引（**インデックス**）を作っておくので、検索のたびにファイルを開く必要がありません（インデックスについては [インデックスとは](about-index.md) で説明します）。探している言葉が、どのファイルの、どのシート・ページ・スライドの、何行目にあるかが一覧になり、ダブルクリックで元のファイルを開けます。

このページでは、動作環境とインストールの方法を説明します。インストールが済んだら、[はじめて使う](quickstart.md) に進んでください。

## 動作環境

| 必要なもの | 用途 |
|---|---|
| Windows 10 / 11 | 最初から入っている Windows PowerShell 5.1 で動きます |
| Microsoft Excel | Excel ファイルから文字を取り出すときに使います |
| Microsoft Word・PowerPoint | 旧形式（.doc・.ppt）のファイルを読み込むときだけ使います |

管理者権限、追加のソフト、PowerShell の実行ポリシーの変更、ネットワークへの接続は、どれも要りません。

検索できるファイルは次のとおりです。

| 種類 | 拡張子 | 結果に表示する場所 |
|---|---|---|
| Excel | .xlsx / .xlsm / .xls / .xlsb | シート（行・セル） |
| Word | .docx / .docm / .doc | ページ（目安）・ヘッダー/フッター・脚注 |
| PowerPoint | .pptx / .pptm / .ppt | スライド・ノート・フッター |

## ダウンロードとインストール

[Releases](https://github.com/hsgwa/tebunko/releases/latest) に 2 つの形で置いています。中身（ツールの本体）は同じです。

| 形 | 向いている場合 |
|---|---|
| インストーラー（`tebunko-setup-<バージョン>.exe`） | 手軽にインストール・更新・アンインストールしたい |
| zip（`tebunko-<バージョン>.zip`） | 実行ファイル（.exe）を入れたくない・入れられない。共有フォルダに置いて使いたい |

### インストーラーで入れる

1. `tebunko-setup-<バージョン>.exe` をダウンロードして実行します。
2. 「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を押します（インストーラーにはまだコード署名がないため表示されます）。
3. 画面に沿って進めます。管理者権限は要りません。既定では、自分のユーザーのフォルダ（`%LOCALAPPDATA%\Programs\tebunko`）に入ります。管理者なら、すべてのユーザー向けに `C:\Program Files` に入れることもできます。
4. スタートメニューの「tebunko」から起動します。

### zip を展開して使う

1. `tebunko-<バージョン>.zip` をダウンロードし、好きな場所に展開します。共有フォルダに置いてもかまいません。
2. 展開した `tebunko` フォルダの `tebunko.bat` をダブルクリックします。

初回は「セキュリティの警告」が表示されます。［実行］を押してください。表示させたくない場合は、先に `tebunko.bat` のプロパティを開き、［ブロックの解除］にチェックを入れておきます。

!!! note "展開したフォルダの中身"
    `tebunko.bat`（起動用）・`scripts`（ツールの本体）・`README.md`・`LICENSE` が入っています。使い始めると、設定ファイル `setting.config` が同じフォルダにできます。

## 起動すると

画面には 4 つのタブがあります。番号は画面の表示のとおりです。

| タブ | できること | 説明 |
|---|---|---|
| ［1 インデックス管理］ | 検索したいフォルダを登録し、インデックスを作る | [インデックスを作る](indexing.md) |
| ［2 検索］ | 言葉で検索し、元のファイルを開く | [検索する](search.md)・[元のファイルを開く](open-files.md) |
| ［8 設定］ | インデックスを置くフォルダ（ワークスペース）を変える | [設定](settings.md) |
| ［9 プロセス停止］ | 残った Excel・Word・PowerPoint を終了する | [Office のプロセスを止める](process.md) |

起動したときに開くタブは状況によって変わります。インデックスがまだ無いときや、前回のインデックス作成が途中で止まっているときは［1 インデックス管理］が、それ以外は［2 検索］が開きます。すでに起動しているときに、もう一度起動すると、開いている画面が前に出ます。
