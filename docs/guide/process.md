# Office プロセスの停止

インデックス作成では、Excel・Word・PowerPoint をウィンドウを表示せずに（バックグラウンドで）起動し、ファイルから文字を抽出します。インデックス作成を中断した場合や Office が応答しなくなった場合、これらのプロセスが残存することがあります。［9 プロセス停止］タブでは、残存した Office プロセスを確認し、終了できます。

## 使用する場面

- インデックス作成の中止後に、PC の動作が重い
- タブの見出しに ⚠ が表示されている（インデックス作成中でないにもかかわらず、バックグラウンドの Office プロセスが残存している）
- Excel・Word・PowerPoint が起動しない、または応答しない
- 取り込みで「Officeアプリが応答しませんでした」などのエラーが発生した

## 一覧の項目

「残っている Office のプロセス」に、実行中の Excel・Word・PowerPoint を表示します。タブの表示中は 5 秒ごとに更新します。［更新］（または F5 キー）で即時に更新できます。

| 列 | 内容 |
|---|---|
| 種類 | Excel・Word・PowerPoint |
| PID | プロセス ID |
| 起動時刻 | プロセスの起動時刻 |
| メモリ | メモリ使用量 |
| ウィンドウ | 表示中のウィンドウ名。空欄の場合は**バックグラウンド**のプロセス（ウィンドウを持たないプロセス。取り込みで起動したものなど） |

## プロセスの終了

| ボタン | 終了の対象 |
|---|---|
| ［バックグラウンドのみ終了］（推奨） | ウィンドウを持たないプロセスのみ。利用者が開いている Excel などは終了しません |
| ［選択したプロセスを終了］ | 一覧で選択したプロセス |
| ［すべて終了］ | 一覧のすべてのプロセス |

いずれの場合も、終了前に確認を表示します。

!!! warning "未保存のデータについて"
    ウィンドウを表示しているプロセスを終了すると、そのプロセスで開いているファイルの未保存の変更は失われます。事前に保存してから終了してください。判断がつかない場合は［バックグラウンドのみ終了］を使用してください。
