# Office のプロセスを止める

インデックス作成は、Excel・Word・PowerPoint を画面に出さずに（バックグラウンドで）動かして、ファイルから文字を取り出します。インデックス作成を途中で止めたときや、Office が応答しなくなったときに、これらのプロセスが残ることがあります。［9 プロセス停止］タブでは、残った Office のプロセスを確かめて終了できます。

## いつ使うか

- インデックス作成を中止した後、PC が重い
- タブの見出しに ⚠ が付いている（バックグラウンドの Office のプロセスが残っていて、インデックス作成中でないとき）
- Excel・Word・PowerPoint が開けない、または開いても反応しない
- 取り込みに「Officeアプリが応答しませんでした」などの失敗が出た

## 一覧の見方

「残っている Office のプロセス」に、動いている Excel・Word・PowerPoint が並びます。タブを開いている間は 5 秒ごとに更新します。［更新］（または F5）ですぐに読み直せます。

| 列 | 内容 |
|---|---|
| 種類 | Excel・Word・PowerPoint |
| PID | プロセスの番号 |
| 起動時刻 | いつ起動したか |
| メモリ | 使っているメモリ |
| ウィンドウ | 画面に出ているウィンドウの名前。空なら**バックグラウンド**（画面にウィンドウが無いプロセス。取り込みで起動したものなど） |

## 終了する

| ボタン | 終了するもの |
|---|---|
| ［バックグラウンドのみ終了］（おすすめ） | 画面にウィンドウが無いプロセスだけ。自分で開いている Excel などはそのまま残ります |
| ［選択したプロセスを終了］ | 一覧で選んだプロセス |
| ［すべて終了］ | 一覧のすべてのプロセス |

どれも、終了する前に確認が出ます。

!!! warning "保存していない内容は失われます"
    画面に表示中のプロセス（ウィンドウのあるもの）を終了すると、そのプロセスで開いているファイルの保存していない内容は失われます。先に保存してから終了してください。迷ったら［バックグラウンドのみ終了］を使います。
