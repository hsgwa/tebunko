# クイックスタート

フォルダの登録から、検索と元のファイルの表示までの基本的な手順を説明します。ここでは例として、共有フォルダ `C:\共有\営業部` から「(株)山田商事」を検索します。

## 1. フォルダの登録

1. ［1 インデックス管理］タブを開きます。
2. ［追加…］を選択し、［参照…］で `C:\共有\営業部` を指定します。パスの入力・貼り付け、またはエクスプローラーからのドラッグ＆ドロップでも指定できます。
3. インデックス名はフォルダ名から自動的に設定されます（後から変更できます）。［OK］を選択すると、一覧に追加されます。

## 2. インデックスの作成

登録したフォルダ内のファイルから文字を抽出し、検索用の索引データ（**インデックス**）を作成します（[インデックスの仕組み](about-index.md)）。

1. 対象のインデックスの［作成］にチェックが入っていることを確認します。
2. ［インデックス作成を開始］を選択します。
3. 「インデックス作成の確認」に取り込み対象のファイル数が表示されます。内容を確認し、［OK］を選択します。

![［1 インデックス管理］タブ。登録したフォルダの一覧と、取り込んだファイルの数が表示されている](../images/readme_index.png)

処理中は進捗と残り時間を表示します。所要時間の目安は、Office ファイル 300 件（大半が Excel）で約 3 分です。2 回目以降は追加・変更されたファイルのみを取り込むため、変更が無ければ数秒で完了します。

インデックスの作成中も検索は可能です。ただし、インデックス作成は tebunko のプロセス内で実行されるため、**画面を閉じると中断されます**。中断した処理は、次回の実行時に続きから再開します。

## 3. 検索

1. ［2 検索］タブを開きます。
2. 検索ワードに「(株)山田商事」と入力し、Enter キーを押します。

該当したファイルが、件数と場所とともに見出しとして一覧表示されます。

![検索直後の結果。該当したファイルが、件数と場所とともに見出しとして並んでいる](../images/readme_results_headings.png)

## 4. 検索結果の確認

ファイルの見出しを選択すると、そのファイルの該当行を展開表示します。一致した文字列は強調表示されます。行を選択すると、前後の行がプレビューに表示されます。

![検索結果。ファイルごとの見出しの下に該当行が強調表示され、下部にプレビューが表示されている](../images/readme_results.png)

## 5. 元のファイルの表示

行をダブルクリック（または Enter キー）すると、元のファイルを開きます。Excel の場合は、該当するセルを選択した状態で開きます。開いたファイルは、そのまま編集・保存できます。
