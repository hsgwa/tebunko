# はじめて使う

フォルダを登録してから、検索して元のファイルを開くまでを、順に説明します。例として、共有フォルダ `C:\共有\営業部` の中から「(株)山田商事」を探します。

## 1. フォルダを登録する

1. ［1 インデックス管理］タブを開きます。
2. ［追加…］を押し、［参照…］で `C:\共有\営業部` を選びます。パスを入力・貼り付けしても、エクスプローラーからフォルダをドラッグ＆ドロップしてもかまいません。
3. インデックス名はフォルダ名から自動で入ります（あとから変えられます）。［OK］で一覧に加わります。

## 2. インデックスを作る

登録したフォルダのファイルから文字を書き写して、検索用の控え（**インデックス**）を作ります。検索はこの控えを使うので、ファイルを 1 つずつ開かずに済みます（くわしくは [インデックスとは](about-index.md)）。

1. 一覧で、作りたいインデックスの［作成］にチェックが付いていることを確かめます。
2. ［インデックス作成を開始］を押します。
3. 「インデックス作成の確認」に、取り込むファイルの数が出ます。内容を確かめて［OK］を押します。

![［1 インデックス管理］タブ。登録したフォルダの一覧と、取り込んだファイルの数が表示されている](../images/readme_index.png)

進み具合と残り時間が画面に出ます。かかる時間の目安は、Office ファイル 300 件（ほとんどが Excel）で約 3 分です。2 回目からは、新しいファイルと変わったファイルだけを取り込むので、変更が無ければ数秒で終わります。

インデックスの作成中も検索できます。ただし、作成は tebunko の画面の中で動いているので、**画面を閉じると止まります**（次は続きから再開します）。

## 3. 検索する

1. ［2 検索］タブを開きます。
2. 検索ワードに「(株)山田商事」と入れ、Enter を押します。

ヒットしたファイルが、件数と場所とともに見出しとして並びます。

![検索した直後の結果。ヒットしたファイルが、件数と場所とともに見出しとして並んでいる](../images/readme_results_headings.png)

## 4. 結果を見る

ファイルの見出しをクリックすると、そのファイルの一致した行が開きます。一致した文字は黄色で表示されます。行を選ぶと、その前後の行が下のプレビューに出ます。

![検索結果。ファイルごとの見出しが並び、開いたファイルの一致した行が黄色で強調され、下にプレビューが出ている](../images/readme_results.png)

## 5. 元のファイルを開く

行をダブルクリックする（または Enter を押す）と、元のファイルが開きます。Excel なら、該当のセルを選んだ状態で開きます。そのまま編集して保存できます。
