# 検索する

［2 検索］タブで、言葉を入れて検索します。検索はインデックスを使うので、ファイルを 1 つも開かずに結果が出ます。

![［2 検索］タブ。検索結果がファイルごとの見出しで並び、下にプレビューが出ている](../images/screenshot_search.png)

## 検索の手順

1. 「検索ワード」に探したい言葉を入れます。
2. Enter を押すか、［検索］を押します。
3. ヒットしたファイルが見出しとして並びます。

検索中に Esc を押すと、検索を中止します。

!!! tip "検索ワードの扱い"
    入れた文字は、空白も含めてそのまま 1 つの文字列として探します（複数の言葉の AND 検索はできません）。［正規表現を使う］がオフなら、`(株)` や `1.5` の記号も、そのままの文字として探します。

## オプション

| オプション | 内容 |
|---|---|
| ［大文字と小文字を区別］ | オンにすると、英字の大文字と小文字を区別します（例: `ID` は `id`・`Id` に一致しない） |
| ［正規表現を使う］ | オンにすると、検索ワードを正規表現として扱います |
| ［図形も検索］ | 図形・テキストボックス・SmartArt・グラフの文字も検索します（最初はオン）。結果の種別は「図形」 |
| ［コメントも検索］ | Excel・Word・PowerPoint のコメント（返信を含む）も検索します（最初はオン）。結果の種別は「コメント」 |
| 対象ファイル | 元のファイル名で、検索するファイルを絞ります（下の「対象ファイルの書き方」） |

オプションは、次に起動したときも同じ状態で始まります。

### 対象ファイルの書き方

元のファイル名に当てて、検索するファイルを絞ります。空ならすべてのファイルが対象です。

| 書き方 | 意味 | 例 |
|---|---|---|
| `;` で区切る | いずれかに当たれば対象 | `*.xlsx;*.xlsm` |
| `*` | 任意の文字列 | `*.xlsx`（Excel の新形式だけ） |
| `?` | 任意の 1 文字 | `見積?.xlsx` |
| `*` も `?` も無い | ファイル名の一部に含まれれば対象（部分一致） | `見積` |
| `!` で始める | 当たるものを除く | `!*old*`（名前に old を含むものを除く） |

例: `*.xlsx;見積;!*old*` は、「.xlsx のファイルか、名前に『見積』を含むファイル。ただし名前に old を含むものは除く」です。大文字と小文字は区別しません。全角の `；` `！` も使えます。

## 検索対象を選ぶ

左の「検索対象」は、インデックスとその中のフォルダのツリーです。チェックしたインデックス・フォルダだけを検索します。［すべて選択］［すべて解除］でまとめて切り替えられます。スペースキーでも、選んでいる項目のチェックを切り替えられます。

## 結果の見方

結果は元のファイルごとの見出しにまとまります。見出しには Excel・Word・PowerPoint の印と件数が出ます。

- 見出しをクリック（または Enter）すると、そのファイルの一致した行を開く・閉じるを切り替えます。
- ［すべて展開］ですべてのファイルの行を、［すべて折りたたむ］で見出しだけを表示します。
- 一致した文字は黄色で表示します。

| 列 | 内容 |
|---|---|
| インデックス | インデックス名（複数のインデックスを検索したときだけ） |
| フォルダ・ファイル名 | 元のファイルの場所 |
| 場所 | Excel のシート、Word のページ・ヘッダー/フッター・脚注、PowerPoint のスライド・ノートなど |
| 種別 | セル・図形・コメントなど、どこにあった文字か |
| 行・セル | 何行目か。Excel はセルの番地（A1 など） |
| 該当行 | 一致した行の文字 |

結果は 10,000 件までです。それを超えるときは、検索ワードや対象ファイルで絞ってください。

## 結果の中から探す

「結果の中から探す」に文字を入れると、今の結果をさらに絞り込めます。表示は「N 件中 K 件を表示」になります。

## プレビュー

結果の行を選ぶと、下のプレビューにその前後の行を表示します。プレビューのセルをクリックして Ctrl+C を押すと、そのセルの値をコピーできます（Shift＋クリック・ドラッグで複数）。プレビューと結果の境目を上下にドラッグすると、プレビューの高さを変えられます。

## 結果をファイルに出力する

［結果をファイルに出力］を押すと、今の結果をワークスペースの `検索結果.txt` に書き出して開きます。ほかの人に結果を渡すときや、一覧を保存しておきたいときに使います。

## 高速検索

検索ワードの下に「高速検索：使用可」または「使用不可」が出ます。使用可のときは、Windows Search で探す範囲を先に絞るので、大きなインデックスでも速く結果が出ます。結果は使用不可のときと同じです。詳しくは [高速検索](fast-search.md) を見てください。
