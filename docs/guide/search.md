# 検索

［2 検索］タブで検索を行います。検索はインデックスを照合して行うため、元のファイルを開くことなく結果を表示します。

![［2 検索］タブ。検索結果がファイルごとの見出しで並び、下にプレビューが出ている](../images/screenshot_search.png)

## 検索の手順

1. 「検索ワード」に検索する文字列を入力します。
2. Enter キーを押すか、［検索］を選択します。
3. 該当したファイルが見出しとして一覧表示されます。

検索中に Esc キーを押すと、検索を中止します。

!!! note "検索ワードの扱い"
    入力した文字列は、空白を含めて 1 つの文字列として検索します。複数語の AND 検索には対応していません。［正規表現を使う］が無効の場合、`(株)` や `1.5` などの記号もリテラル（文字どおり）として扱います。

## 検索オプション

| オプション | 内容 |
|---|---|
| ［大文字と小文字を区別］ | 有効にすると、英字の大文字と小文字を区別します（例：`ID` は `id`・`Id` に一致しません） |
| ［正規表現を使う］ | 有効にすると、検索ワードを正規表現として解釈します |
| ［図形も検索］ | 図形・テキストボックス・SmartArt・グラフの文字列も検索対象とします（既定：有効）。結果の種別は「図形」です |
| ［コメントも検索］ | Excel・Word・PowerPoint のコメント（返信を含む）も検索対象とします（既定：有効）。結果の種別は「コメント」です |
| 対象ファイル | 元のファイル名で検索対象を限定します（「対象ファイルの指定方法」を参照） |

オプションの設定は保存され、次回起動時にも引き継がれます。

### 対象ファイルの指定方法

元のファイル名に対して条件を指定し、検索対象を限定します。空欄の場合はすべてのファイルが対象です。

| 記法 | 意味 | 例 |
|---|---|---|
| `;` で区切る | いずれかの条件に一致するファイルを対象とする | `*.xlsx;*.xlsm` |
| `*` | 任意の文字列 | `*.xlsx`（Excel の新形式のみ） |
| `?` | 任意の 1 文字 | `見積?.xlsx` |
| `*`・`?` を含まない | ファイル名の部分一致 | `見積` |
| `!` で始める | 一致するファイルを除外する | `!*old*`（名前に old を含むファイルを除外） |

例：`*.xlsx;見積;!*old*` は、「拡張子が .xlsx のファイル、または名前に『見積』を含むファイル。ただし名前に old を含むファイルは除く」を意味します。大文字と小文字は区別しません。全角の `；`・`！` も使用できます。

## 検索対象の選択

画面左側の「検索対象」には、インデックスとその配下のフォルダがツリーで表示されます。チェックを付けたインデックス・フォルダのみを検索します。［すべて選択］［すべて解除］で一括して切り替えられます。スペースキーで、選択中の項目のチェックを切り替えることもできます。

## 検索結果

検索結果は元のファイルごとの見出しにまとめて表示します。見出しには、ファイルの種類（Excel・Word・PowerPoint）と該当件数を表示します。

- 見出しを選択（または Enter キー）すると、そのファイルの該当行の表示・非表示を切り替えます。
- ［すべて展開］ですべてのファイルの該当行を、［すべて折りたたむ］で見出しのみを表示します。
- 一致した文字列は強調表示します。

| 列 | 内容 |
|---|---|
| インデックス | インデックス名（複数のインデックスを検索した場合のみ） |
| フォルダ・ファイル名 | 元のファイルの格納場所 |
| 場所 | Excel のシート、Word のページ・ヘッダー/フッター・脚注、PowerPoint のスライド・ノートなど |
| 種別 | セル・図形・コメントなど、文字列の格納元 |
| 行・セル | 行番号。Excel の場合はセル番地（A1 など） |
| 該当行 | 一致した行の内容 |

表示できる検索結果は 10,000 件までです。これを超える場合は、検索ワードまたは対象ファイルの条件で絞り込んでください。

## 検索結果の絞り込み

「結果の中から探す」に文字列を入力すると、現在の検索結果をさらに絞り込みます。表示は「N 件中 K 件を表示」となります。

## プレビュー

検索結果の行を選択すると、プレビューに前後の行を表示します。プレビューのセルを選択して Ctrl+C キーを押すと、セルの値をコピーできます（Shift キーを押しながらのクリック、またはドラッグで複数選択）。検索結果とプレビューの境界を上下にドラッグすると、プレビューの高さを変更できます。

## 検索結果の出力

［結果をファイルに出力］を選択すると、現在の検索結果をワークスペースの `検索結果.txt` に出力し、そのファイルを開きます。検索結果の共有や記録に使用します。

## 高速検索

検索ワードの下に「高速検索：使用可」または「高速検索：使用不可」を表示します。使用可の場合は Windows Search で検索範囲を事前に絞り込むため、大規模なインデックスでも短時間で結果を表示します。検索結果は使用不可の場合と同一です。詳細は [高速検索](fast-search.md) を参照してください。
