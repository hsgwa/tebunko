# 更新とアンインストール

## 更新

新しいバージョンは [Releases](https://github.com/hsgwa/tebunko/releases/latest) で配布しています。更新の前に tebunko を終了してください。

### インストーラー版

新しいバージョンのインストーラー（`tebunko-setup-<バージョン>.exe`）を実行します。設定（登録したフォルダなど）とインデックスは引き継がれます。tebunko の起動中は、インストーラーの処理を続行できません。

### zip 版

新しいバージョンの zip を展開し、現在の `tebunko` フォルダと置き換えます。

- **同じ場所に上書きする場合**：設定ファイル `setting.config` は zip に含まれないため、そのまま保持されます。
- **別の場所に展開する場合**：現在のフォルダの `setting.config` を新しいフォルダにコピーしてください。コピーしない場合、インデックスの一覧が空の状態で起動します。この状態でインデックス作成を実行すると、一覧に無いインデックスは削除されます。

インデックスはワークスペース（既定：`Documents\tebunko_ws`）に保存されているため、tebunko のフォルダを置き換えても削除されません。

!!! warning "互換性の無い変更を含むバージョン"
    リリースノートに「互換が無くなる変更」が記載されているバージョンでは、既存の設定やインデックスをそのまま使用できない場合があります。更新前に、リリースノートの移行手順を確認してください。

## アンインストール

アンインストールしても、**ワークスペース（インデックス）は削除されません**。インデックスには文書の本文が含まれるため、不要な場合は手動で削除してください。

### インストーラー版

1. tebunko を終了します。
2. Windows の［設定］→［アプリ］で「tebunko」を選択し、アンインストールします。

tebunko の本体と設定ファイルが削除されます。ワークスペースの場所は、アンインストールの完了時に表示されます。

### zip 版

tebunko を終了し、`tebunko` フォルダを削除します。レジストリへの書き込みは行っていないため、他に削除するものはありません。

### 残存するデータの削除

| 場所 | 内容 |
|---|---|
| ワークスペース（既定：`%USERPROFILE%\Documents\tebunko_ws`。変更した場合はその場所） | インデックス・取り込み一覧・ログ |
| `%LOCALAPPDATA%\tebunko` | tebunko を書き込み不可の場所に配置した場合の設定ファイル（存在しない場合は未使用です） |
| Windows Search の「インデックスのオプション」 | ワークスペースを索引付けの対象に追加していた場合は、対象から除外します |
