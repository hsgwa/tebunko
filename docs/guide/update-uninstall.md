# 更新とアンインストール

## 更新

新しいバージョンは [Releases](https://github.com/hsgwa/tebunko/releases/latest) で配布しています。更新の前に tebunko を終了してください。

### インストーラー版

新しいバージョンのインストーラー（`tebunko-setup-<バージョン>.exe`）を実行します。設定（登録したフォルダなど）とインデックスは引き継がれます。ただし、「すべてのユーザー」（`C:\Program Files` など書き込めない場所）に入れていた場合は、前の版が `%LOCALAPPDATA%` に置いていた設定が引き継がれません。インストーラーの最後の「tebunko を起動する」は外し、起動する前に、[前の版からの移行](#前の版からの移行設定の置き場所の変更)の手順を行ってください。tebunko の起動中は、インストーラーの処理を続行できません。

### zip 版

新しいバージョンの zip は、現在のフォルダには重ねず、別のフォルダに展開します（重ねて展開すると、前のバージョンにあって新しいバージョンに無いスクリプトが残るためです）。

1. 新しい zip を、展開する前に解除します（［ブロックの解除］、Windows 11 では［許可する］。[zip による配置](index.md#zip-による配置)）。
2. 別のフォルダに展開します。
3. 現在のフォルダの `setting.config` を新しいフォルダにコピーします。ツールのフォルダに書けなくて設定が既定のワークスペース（`%USERPROFILE%\Documents\tebunko_ws`）の直下にある場合は、コピーは要りません。前の版で設定が `%LOCALAPPDATA%\tebunko\<英数字 16 文字のフォルダ>\setting.config` にあった場合は、[前の版からの移行](#前の版からの移行設定の置き場所の変更)を見てください。コピーしない場合、インデックスの一覧が空の状態で起動します。この状態でインデックス作成を実行すると、一覧に無いインデックスは削除されます。
4. [ショートカットを作っていた場合](index.md#tebunkobat-を使わずに起動するzip-版)は、リンク先と作業フォルダーを新しいフォルダに直します。
5. 前のフォルダを削除します。

### 単一 .ps1 版（試験版）

新しい `tebunko-<バージョン>.ps1` を、現在の `.ps1` と同じフォルダに置きます。古い `.ps1` は削除します。`setting.config` は `.ps1` とは別のファイルなので、そのまま保持されます。別のフォルダに置く場合は、`setting.config` を新しいフォルダにコピーしてください。

インデックスはワークスペース（既定：`Documents\tebunko_ws`）に保存されているため、tebunko のフォルダを置き換えても削除されません。

!!! warning "互換性の無い変更を含むバージョン"
    リリースノートに「互換が無くなる変更」が記載されているバージョンでは、既存の設定やインデックスをそのまま使用できない場合があります。更新前に、リリースノートの移行手順を確認してください。

## アンインストール

アンインストールしても、**ワークスペース（インデックス）は削除されません**。インデックスには文書の本文が含まれるため、不要な場合は手動で削除してください。

### インストーラー版

1. tebunko を終了します。
2. Windows の［設定］→［アプリ］で「tebunko」を選択し、アンインストールします。

tebunko の本体と設定ファイルが削除されます。ワークスペースの場所は、アンインストールの完了時に表示されます。

### zip 版

tebunko を終了し、`tebunko` フォルダを削除します。レジストリへの書き込みは行っていないため、他に削除するものはありません。

### 単一 .ps1 版（試験版）

tebunko を終了し、`.ps1` を削除します。同じフォルダの `setting.config` も、不要なら削除します。レジストリへの書き込みは行っていません。

### 残存するデータの削除

| 場所 | 内容 |
|---|---|
| ワークスペース（既定：`%USERPROFILE%\Documents\tebunko_ws`。変更した場合はその場所） | インデックス・取り込み一覧・ログ・一時ファイル |
| tebunko のフォルダ内の `setting.config`・`startup_error.txt` | 設定ファイルと、起動が失敗したときの記録（書き込めない場所に配置した場合、設定ファイルは上のワークスペースの直下に置かれ、起動の記録は作られません）。アンインストーラーは、この 2 つも消します |
| `%LOCALAPPDATA%\tebunko` | 前の版が作ったフォルダです（今の版は書き込みません）。残っていれば、フォルダごと削除して構いません |
| Windows Search の「インデックスのオプション」 | 本文のインデックス（`content_index`）は、tebunko が索引付けの対象から自動で外します。ワークスペースを自分で索引付けの対象に追加していた場合だけ、対象から除外します |

## 前の版からの移行（設定の置き場所の変更）

今の版の tebunko は、`%LOCALAPPDATA%` と `%TEMP%` に何も書きません。設定ファイル（`setting.config`）は、tebunko のフォルダに書き込めればそこに、書き込めなければ既定のワークスペース（`%USERPROFILE%\Documents\tebunko_ws`）の直下に置きます。起動に失敗したときの記録（`startup_error.txt`）は、tebunko のフォルダにだけ書き、書き込めないときは記録を残さずに理由だけを示します。`%LOCALAPPDATA%\tebunko\<英数字 16 文字のフォルダ>\setting.config` に置いていた前の版の設定は、今の版では読まれません。`C:\Program Files` などの書き込めない場所に入れていた方は、次のとおり移してください。

1. tebunko を終了します。**移し終えるまで、インデックス作成を実行しないでください。**
2. 既定のワークスペースのフォルダ（`%USERPROFILE%\Documents\tebunko_ws`）が無ければ作ります。
3. `%LOCALAPPDATA%\tebunko\<英数字 16 文字のフォルダ>\setting.config` を、2 のフォルダの直下（`%USERPROFILE%\Documents\tebunko_ws\setting.config`）にコピーします。
4. tebunko を起動し、［設定］の「設定ファイル」の場所が、コピーした先になっていることを確かめます。
5. 問題がなければ、`%LOCALAPPDATA%\tebunko` を削除します。

`<英数字 16 文字のフォルダ>` は、前の版が tebunko のフォルダごとに 1 つずつ作ったものです（名前は tebunko のフォルダのパスから決まります）。複数ある場合は、前の版で使っていた tebunko のフォルダのものを移します。どれか分からなければ、`setting.config` の更新日時が新しいものを選んでください。設定の `workspaceFolder` に手で相対パスを書いていた場合は、設定ファイルのあるフォルダからの位置として読まれるため、移すと起点が `tebunko_ws` に変わります。絶対パスに書き直してください。

設定を移さずに起動したときは、クロール対象フォルダの一覧が空の状態で始まります。一覧が空のままならインデックス作成は始まらず、インデックスは消えません。ところが、フォルダを 1 つでも登録してインデックス作成を実行すると、前回の一覧にあって今の一覧に無いフォルダのインデックスは削除されます。コピーしなかったときは、［設定］でワークスペースを選び直し、クロール対象フォルダを前の版と同じ内容で登録し直してから実行してください。

ワークスペースを別のフォルダにしていた方も、設定ファイルの置き場所は既定のワークスペースの直下です。設定ファイルは、ワークスペースの中身としては数えません。ワークスペースの移動・［消して最初から］・エクスポートでも、移動も削除もされません。
