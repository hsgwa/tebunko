# 更新とアンインストール

## 新しい版に更新する

新しい版は [Releases](https://github.com/hsgwa/tebunko/releases/latest) に置いています。更新する前に、tebunko を閉じてください。

### インストーラーで入れた場合

新しい版のインストーラー（`tebunko-setup-<バージョン>.exe`）を実行するだけです。設定（登録したフォルダなど）とインデックスはそのまま引き継ぎます。tebunko を起動したままだと、インストーラーは先に進みません。

### zip で使っている場合

新しい版の zip を展開し、今の `tebunko` フォルダを置き換えます。

- **同じ場所に上書きする**：設定ファイル `setting.config` は zip に入っていないので、そのまま残ります。
- **別の場所に展開する**：今のフォルダの `setting.config` を、新しいフォルダにコピーしてください。コピーしないと、インデックスの一覧が空のまま始まります。その状態でインデックスを作ると、一覧に無いインデックスは消えます。

インデックスはワークスペース（既定は `Documents\tebunko_ws`）にあるので、tebunko のフォルダを置き換えても消えません。

!!! warning "前の版と互換の無い変更があるとき"
    リリースノートに「互換が無くなる変更」がある版では、設定やインデックスがそのまま使えないことがあります。更新する前に、リリースノートの移行の手順を読んでください。

## アンインストールする

アンインストールしても、**ワークスペース（インデックス）は消えません**。インデックスには文書の文字がそのまま入っているので、要らなければ手で削除してください。

### インストーラーで入れた場合

1. tebunko を閉じます。
2. Windows の［設定］→［アプリ］で「tebunko」を選び、アンインストールします。

tebunko の本体と設定ファイルが消えます。ワークスペースの場所は、アンインストールの最後に表示されます。

### zip で使っている場合

tebunko を閉じて、`tebunko` フォルダを削除します。レジストリには何も書いていないので、ほかに消すものはありません。

### 残るものを消す

| 場所 | 中身 |
|---|---|
| ワークスペース（既定は `%USERPROFILE%\Documents\tebunko_ws`。変えた場合はその場所） | インデックス・取り込み一覧・ログ |
| `%LOCALAPPDATA%\tebunko` | tebunko を書き込めない場所に置いたときの設定ファイル（無ければ使っていません） |
| Windows Search の「インデックスのオプション」 | ワークスペースを対象に加えていた場合は、外します |
