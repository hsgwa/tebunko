# 高速検索

インデックスの規模が大きくなると、すべての索引データの照合に時間を要します。**高速検索**は、Windows に標準搭載の Windows Search を使用して、検索ワードを含む可能性のあるフォルダを事前に絞り込み、そのフォルダのみを照合する機能です。検索結果は、すべてを照合した場合と同一です。

## 利用可否の確認

［2 検索］の検索ワードの下に、高速検索の状態を表示します。表示を押すと、Windows Search の状態を確かめ直し、今の状態・反映の進み具合・使用不可の場合の直し方を詳しく表示します。

| 表示 | 意味 |
|---|---|
| 高速検索：使用可 | Windows Search で検索範囲を絞り込んでから照合します |
| 高速検索：使用可（反映 80%） | 使用できます。高速検索用のインデックスの一部（この例では 2 割のフォルダ）がまだ Windows Search に反映されておらず、その部分はすべてを照合します。反映が進むと数字が増え、100% になると `（反映 …）` は消えます |
| 高速検索：使用不可（…） | すべてのインデックスを照合します（検索結果は同一で、所要時間のみが異なります）。括弧の中が理由です（下の表） |
| 高速検索：確認中… | 表示を押して、Windows Search の状態を確かめています（終わると詳しい画面を表示します） |

## 使用不可の理由と直し方

| 括弧の中 | 理由 | 直し方 |
|---|---|---|
| （正規表現） | ［正規表現を使う］が有効です | 正規表現を使わないときは、チェックを外します |
| （1 文字） | 検索ワードに 2 文字以上の部分がありません | 2 文字以上のワードで検索します |
| （インデックスがありません） | ワークスペースに `system_index` がありません（インデックスを作成していない、またはワークスペースが違います） | ［1 インデックス管理］でインデックスを作成します。ワークスペースを変えた場合は、そのワークスペースにインデックスがあるかも確かめます |
| （Windows Search に接続できません） | Windows Search を開けない、または問い合わせに失敗しました（時間切れを含みます） | Windows Search のサービス（WSearch）が動いているか確かめ、止まっているときは開始します |
| （Windows Search の対象外） | `system_index` が索引されておらず、ワークスペースの中も 1 件も索引されていません | ［インデックスのオプション］でワークスペースの `system_index` を対象に加えます（下の「推奨設定」）。管理者の権限が要り変更できない PC では、PC の管理者に依頼します |
| （Windows Search の準備中） | `system_index` は索引の対象ですが、まだ索引されていません | 待ちます（数分〜数時間）。索引が終わると使用可になります |

「対象外」と「準備中」は、`system_index` が索引されていないとき、ワークスペースの中のほかのもの（ログなど）が索引されているかで見分けています（管理者の権限なしに索引の対象の一覧を読む方法が無いためです）。作ったばかりのワークスペースでは、対象でも「対象外」と表示されることがあります。しばらくしてから、もう一度表示を押してください。

［正規表現を使う］・1 文字のワードと Windows Search の理由が重なるときは、その場で直せる［正規表現を使う］・1 文字の理由を表示します。

## 状態を確かめ直す時機

次のときに確かめ直します。

- 画面を開いたとき、ワークスペースを変えたとき
- インデックス作成が終わったとき
- 検索のたび（使用不可の理由だけ。反映の進み具合は前の値のままです）
- 表示を押したとき（このときだけ、詳しい画面を表示します）
- 準備中（Windows Search の準備中、または反映待ちのフォルダがある間）は、5 分おき。準備が終わると止まります

## 推奨設定

インデックス作成では、検索に使うデータ（ワークスペースの `content_index`）に加えて、Windows Search に索引させるデータ（`system_index`）を作成します。どちらもインデックスの一部です。ワークスペースの既定の場所（`Documents\tebunko_ws`）は、標準で Windows Search の索引付けの対象です。

ただし、`content_index` も索引付けの対象に含まれていると、Windows Search がその処理に時間を要し、高速検索が有効になるまで 1 日以上かかる場合があります。次の手順で `content_index` を対象から除外してください。

1. ［スタート］から「インデックスのオプション」を開きます。
2. ［変更］を選択します。
3. ワークスペース（既定：`ドキュメント\tebunko_ws`）配下の `content_index` のチェックを外します。
4. `system_index` のチェックは有効のままにします。

ワークスペースを Windows Search の対象外の場所（別のドライブなど）に変更した場合は、同じ画面でそのワークスペースの `system_index` にチェックを付けると、高速検索を利用できます。
