# 高速検索

インデックスの規模が大きくなると、すべての索引データの照合に時間を要します。**高速検索**は、Windows に標準搭載の Windows Search を使用して、検索ワードを含む可能性のあるフォルダを事前に絞り込み、そのフォルダのみを照合する機能です。検索結果は、すべてを照合した場合と同一です。

## 利用可否の確認

［2 検索］の検索ワードの下に、次のいずれかを表示します。

| 表示 | 意味 |
|---|---|
| 高速検索：使用可 | Windows Search で検索範囲を絞り込んでから照合します |
| 高速検索：使用不可 | すべてのインデックスを照合します（検索結果は同一で、所要時間のみが異なります） |

次の場合は使用不可となります。

- ［正規表現を使う］が有効な場合
- 検索ワードが 1 文字の場合
- Windows Search を利用できない場合（Windows Search サービスが停止している、ワークスペースの `system_index` の索引付けが完了していない、など）

## 推奨設定

インデックス作成では、検索用のインデックス（ワークスペースの `index`）とは別に、Windows Search に索引させるデータ（`system_index`）を作成します。ワークスペースの既定の場所（`Documents\tebunko_ws`）は、標準で Windows Search の索引付けの対象です。

ただし、`index` も索引付けの対象に含まれていると、Windows Search がその処理に時間を要し、高速検索が有効になるまで 1 日以上かかる場合があります。次の手順で `index` を対象から除外してください。

1. ［スタート］から「インデックスのオプション」を開きます。
2. ［変更］を選択します。
3. ワークスペース（既定：`ドキュメント\tebunko_ws`）配下の `index` のチェックを外します。
4. `system_index` のチェックは有効のままにします。

ワークスペースを Windows Search の対象外の場所（別のドライブなど）に変更した場合は、同じ画面でそのワークスペースの `system_index` にチェックを付けると、高速検索を利用できます。
