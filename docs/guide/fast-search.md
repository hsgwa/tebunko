# 高速検索

インデックスが大きくなると、すべてを探すのに時間がかかります。**高速検索**は、Windows に最初から入っている Windows Search を使って、検索ワードを含みうるフォルダを先に絞り、その中だけを探す仕組みです。結果は、すべてを探したときと同じです。

## 使えるかどうかを見る

［2 検索］の検索ワードの下に、次のどちらかが出ます。

| 表示 | 意味 |
|---|---|
| 高速検索：使用可 | Windows Search で範囲を絞ってから探します |
| 高速検索：使用不可 | すべてのインデックスを探します（結果は同じで、時間がかかるだけです） |

次のときは使用不可になります。

- ［正規表現を使う］がオンのとき
- 検索ワードが 1 文字のとき
- Windows Search が使えないとき（Windows Search のサービスが止まっている、ワークスペースの `system_index` がまだ索引されていない、など）

## 高速検索を早く効かせる（おすすめの設定）

インデックス作成は、検索用のインデックス（ワークスペースの `index`）とは別に、Windows Search に索引させるファイル（`system_index`）を作ります。ワークスペースの既定の場所（`Documents\tebunko_ws`）は、もともと Windows Search の対象です。

ただし、`index` も Windows Search の対象のままだと、Windows Search がその処理に時間を取られ、高速検索が効くまで 1 日以上かかることがあります。次のように `index` を対象から外してください。

1. ［スタート］で「インデックスのオプション」を開きます。
2. ［変更］を押します。
3. ワークスペース（既定は `ドキュメント\tebunko_ws`）の下の `index` のチェックを外します。
4. `system_index` にはチェックが付いたままにします。

ワークスペースを Windows Search の対象でない場所（別のドライブなど）に変えたときは、同じ画面でそのワークスペースの `system_index` にチェックを付けると、高速検索が使えるようになります。
