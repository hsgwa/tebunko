# 困ったとき

よくある症状と、その原因・対処をまとめます。ここに無いときは、ページの最後の「解決しないとき」を見てください。

## 起動しない・画面が出ない

| 症状 | 対処 |
|---|---|
| 「セキュリティの警告」が出る（zip 版） | ［実行］を押します。毎回出したくないときは、`tebunko.bat` のプロパティで［ブロックの解除］にチェックを入れます |
| 「Windows によって PC が保護されました」が出る（インストーラー） | ［詳細情報］→［実行］を押します。インストーラーにまだコード署名が無いために出ます |
| ダブルクリックしても何も起きない | すでに起動していないか確かめます（2 つ目を起動すると、開いている画面が前に出ます）。会社の PC で PowerShell の実行が制限されている場合は、情報システム部門に [安全性](../safety/index.md) を見せて相談してください |
| 起動すると［8 設定］が開く | 既定のワークスペースに tebunko 以外のファイルがあります。空のフォルダを選んでください（[設定](settings.md#ワークスペース)） |

## インデックス作成が進まない・止まった

| 症状 | 原因と対処 |
|---|---|
| 「チェックの付いたクロール対象フォルダがありません」 | ［1 インデックス管理］で、取り込むインデックスの［作成］にチェックを付けます |
| 「クロール対象フォルダが見つからなくなったため、インデックス作成を中止しました」 | 作成中にネットワークが切れた、USB メモリを外した、などでフォルダが見えなくなりました。フォルダを使えるようにしてから、もう一度始めると続きから取り込みます |
| 「setting.config を読み込めません」 | 設定ファイルを手で編集して壊した可能性があります。直すか、削除して画面で設定し直します |
| 画面を閉じたら止まった | インデックス作成は画面の中で動いているため、閉じると止まります。次に［続きから再開］で残りを取り込みます |
| 同じファイルで長く止まっている | 1 ファイルが 10 分を超えると、そのファイルを失敗にして次へ進みます。待つか、［中止］して［9 プロセス停止］で残った Office を終了します |
| 遅い | 大きなファイルが多いと時間がかかります。2 回目からは変わったファイルだけを取り込むので速くなります |

止まったときの詳しい理由は、［ログを開く］で `インデックス作成ログ.txt` を見ると分かります。

## 取り込みに失敗したファイルがある

［1 インデックス管理］の「⚠ 取り込みに失敗したファイル」に出ている「失敗の原因」ごとの対処です。

| 失敗の原因（の始まり） | 対処 |
|---|---|
| 読み取りパスワードが設定されているため開けません | 取り込めません。パスワードを外したコピーを置けば取り込めます |
| ファイルが壊れているか、拡張子と中身の形式が一致していません | 正しい拡張子に直すか、正しいファイルに差し替えます |
| ほかのアプリ・利用者がファイルを使用中のため読めません | ファイルを閉じてから、再取り込みします |
| ファイルを読むアクセス権がありません | フォルダの管理者に読み取りの権限を付けてもらいます |
| ファイルが見つかりません | 取り込む間に移動・削除されました。次のインデックス作成で一覧から自動で除かれます |
| 10 分以内に取り込みが終わらなかったため中止しました | Office で開いて確かめます（大きすぎる、開くとダイアログが出る、など） |
| Officeアプリ（Excel・Word・PowerPoint）を起動できませんでした | Office のインストールとライセンス認証の状態を確かめます |
| Officeアプリが応答しませんでした | ［9 プロセス停止］で残った Office を終了してから、再取り込みします |
| シート・文書が大きすぎて取り込めません | シートを分けるか、メモリの多い PC で取り込みます |

直したら、「インデックス作成の確認」で「前回取り込みに失敗し、その後更新されていないファイル N 件も再取り込みする」にチェックを付けて取り込みます（ファイルを更新したときは、チェックが無くても取り込みます）。

すべてのメッセージと意味は、設計書の [エラーメッセージ一覧](../design/indexer/errors.md) にあります。

## 検索で見つからない

| 確かめること | 説明 |
|---|---|
| 検索対象にチェックが付いているか | 左の「検索対象」で、探したいインデックス・フォルダにチェックが付いているか確かめます |
| 対象ファイルで絞っていないか | 「対象ファイル」が空でなければ、そのファイル名に当たるものだけを探します |
| インデックスが最新か | 元のファイルを変えた内容は、次にインデックスを作ったときに反映されます |
| ［図形も検索］［コメントも検索］ | 図形・コメントの中の文字は、これがオンのときだけ探します |
| 表示の形 | Excel の数値は表示されている形（`1,234` など）で探します（[できないこと](limitations.md#excel-の数値)） |
| 取り込みに失敗していないか | そのファイルが「取り込みに失敗したファイル」に出ていないか確かめます |

## 高速検索が「使用不可」のまま

正規表現・1 文字のワードでは使いません。それ以外で使用不可のときは、Windows Search がワークスペースの `system_index` を索引しているか確かめてください（[高速検索](fast-search.md)）。使用不可でも、結果は同じで時間がかかるだけです。

## 元のファイルが開けない

- 「<ファイル名> が見つかりません」と出る：元のフォルダを移したか、名前を変えました。［フォルダを選ぶ］で移した先を選びます（[元のファイルを開く](open-files.md#元のファイルが見つからないとき)）。
- ほかの人が編集中で開けない：開き方を［新規（元のファイルを占有しない）］にすると開けます。
- Excel が反応しない：［9 プロセス停止］で［バックグラウンドのみ終了］を押してから、もう一度開きます。

## ログの場所

ログはワークスペース（既定は `%USERPROFILE%\Documents\tebunko_ws`）にあります。

| ファイル | 中身 |
|---|---|
| `インデックス作成ログ.txt` | インデックス作成の経過と、失敗したファイルの原因。インデックス作成ごとに上書きします。［ログを開く］で開けます |
| `画面エラー.txt` | 画面で起きた予期しないエラーの記録。追記します |

## 解決しないとき

[サポート](https://github.com/hsgwa/tebunko/blob/main/.github/SUPPORT.ja.md) を見て、GitHub の Issue で質問・報告してください。報告するときは、tebunko のバージョン、Windows と Office のバージョン、ログの該当部分を添えてください。ログやファイル名に社外秘の情報が含まれていないか、貼る前に確かめてください。
