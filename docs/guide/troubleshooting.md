# トラブルシューティング

主な症状と、その原因および対処方法をまとめます。該当する項目が無い場合は、本ページ末尾の「サポート」を参照してください。

## 起動できない場合

| 症状 | 対処 |
|---|---|
| 「セキュリティの警告」が表示される（zip 版） | ［実行］を選択します。毎回の表示を避ける場合は、`tebunko.bat` のプロパティで［ブロックの解除］を有効にします |
| 「Windows によって PC が保護されました」が表示される（インストーラー版） | ［詳細情報］→［実行］を選択します。インストーラーがコード署名されていないために表示されます |
| 起動操作をしても画面が表示されない | tebunko が既に起動していないか確認してください（既に起動している場合は、既存のウィンドウが前面に表示されます）。組織のポリシーで PowerShell の実行が制限されている場合は、[安全性](../safety/index.md) の資料を添えて情報システム部門に確認してください |
| 起動時に［8 設定］が表示される | 既定のワークスペースに tebunko 以外のファイルが存在します。空のフォルダを指定してください（[設定](settings.md#ワークスペース)） |

## インデックス作成が完了しない場合

| 症状 | 原因と対処 |
|---|---|
| 「チェックの付いたクロール対象フォルダがありません」 | ［1 インデックス管理］で、取り込むインデックスの［作成］にチェックを付けてください |
| 「クロール対象フォルダが見つからなくなったため、インデックス作成を中止しました」 | 処理中にネットワークの切断や USB メモリの取り外しなどにより、フォルダにアクセスできなくなりました。フォルダにアクセスできる状態に戻してから再実行すると、続きから取り込みます |
| 「setting.config を読み込めません」 | 設定ファイルが破損している可能性があります。内容を修正するか、ファイルを削除して画面から設定し直してください |
| 画面を閉じたら処理が停止した | インデックス作成は tebunko のプロセス内で実行されるため、画面を閉じると中断されます。［続きから再開］で残りを取り込んでください |
| 特定のファイルで処理が進まない | 1 ファイルの処理が 10 分を超えると、そのファイルを失敗として次のファイルに進みます。完了を待つか、［中止］したうえで［9 プロセス停止］から残存した Office プロセスを終了してください |
| 処理に時間がかかる | サイズの大きいファイルが多い場合は時間を要します。2 回目以降は追加・変更されたファイルのみを取り込むため、短時間で完了します |

停止した原因の詳細は、［ログを開く］で `インデックス作成ログ.txt` を確認してください。

## 取り込みに失敗したファイルがある場合

［1 インデックス管理］の「⚠ 取り込みに失敗したファイル」に表示される「失敗の原因」ごとの対処方法です。

| 失敗の原因（冒頭部分） | 対処 |
|---|---|
| 読み取りパスワードが設定されているため開けません | 取り込めません。パスワードを解除したコピーであれば取り込めます |
| ファイルが壊れているか、拡張子と中身の形式が一致していません | 拡張子を修正するか、正常なファイルに差し替えてください |
| ほかのアプリ・利用者がファイルを使用中のため読めません | ファイルを閉じてから、再度取り込んでください |
| ファイルを読むアクセス権がありません | フォルダの管理者に読み取り権限の付与を依頼してください |
| ファイルが見つかりません | 取り込み中にファイルが移動または削除されました。次回のインデックス作成で一覧から自動的に除外されます |
| 10 分以内に取り込みが終わらなかったため中止しました | 該当ファイルを Office で開き、サイズや表示されるダイアログの有無を確認してください |
| Officeアプリ（Excel・Word・PowerPoint）を起動できませんでした | Office のインストール状態とライセンス認証の状態を確認してください |
| Officeアプリが応答しませんでした | ［9 プロセス停止］で残存した Office プロセスを終了してから、再度取り込んでください |
| シート・文書が大きすぎて取り込めません | シートを分割するか、メモリ容量の大きい PC で取り込んでください |

原因を解消した後、「インデックス作成の確認」で「前回取り込みに失敗し、その後更新されていないファイル N 件も再取り込みする」にチェックを付けて実行します（ファイルを更新した場合は、チェックが無くても取り込みの対象となります）。

すべてのメッセージとその意味は [エラーメッセージ一覧](../design/indexer/errors.md) を参照してください。

## 検索結果に表示されない場合

| 確認項目 | 内容 |
|---|---|
| 検索対象 | 画面左側の「検索対象」で、対象のインデックス・フォルダにチェックが付いているか確認してください |
| 対象ファイル | 「対象ファイル」に条件が指定されている場合、条件に一致するファイルのみが検索対象となります |
| インデックスの更新 | 元のファイルの変更は、次回のインデックス作成後に反映されます |
| ［図形も検索］［コメントも検索］ | 図形・コメント内の文字は、これらが有効な場合のみ検索対象となります |
| 表示形式 | Excel の数値は表示形式どおり（`1,234` など）に検索します（[制限事項](limitations.md#excel-の数値)） |
| 取り込みの失敗 | 該当ファイルが「取り込みに失敗したファイル」に含まれていないか確認してください |

## 高速検索が「使用不可」となる場合

正規表現による検索、または 1 文字の検索ワードでは、高速検索は使用しません。それ以外の場合は、Windows Search がワークスペースの `system_index` を索引付けしているか確認してください（[高速検索](fast-search.md)）。使用不可の場合も、検索結果は同一です。

## 元のファイルを開けない場合

- 「<ファイル名> が見つかりません」と表示される：元のフォルダが移動または名前変更されています。［フォルダを選ぶ］で移動先を指定してください（[元のファイルを開く](open-files.md#元のファイルが見つからない場合)）。
- 他の利用者が編集中で開けない：開き方を［新規（元のファイルを占有しない）］に変更してください。
- Excel が応答しない：［9 プロセス停止］で［バックグラウンドのみ終了］を実行してから、再度開いてください。

## ログファイル

ログはワークスペース（既定：`%USERPROFILE%\Documents\tebunko_ws`）に保存されます。

| ファイル | 内容 |
|---|---|
| `インデックス作成ログ.txt` | インデックス作成の経過と、取り込みに失敗したファイルの原因。インデックス作成ごとに上書きされます。［ログを開く］で表示できます |
| `画面エラー.txt` | 画面で発生した予期しないエラーの記録。追記されます |
