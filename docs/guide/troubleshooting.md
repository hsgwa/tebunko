# トラブルシューティング

主な症状と、その原因および対処方法をまとめます。該当する項目が無い場合は、本ページ末尾の「サポート」を参照してください。

## 起動できない場合

| 症状 | 対処 |
|---|---|
| 「セキュリティの警告」が表示される（zip 版） | zip を解除せずに展開した場合に表示されることがあります。［実行］を選択します。次の更新からは、展開する前に zip のプロパティで［ブロックの解除］（Windows 11 では［許可する］）を有効にしてください（[zip による配置](index.md#zip-による配置)）。`tebunko.bat` のプロパティで解除しても避けられます |
| 単一 .ps1 版（試験版）を右クリックしても実行できない・止められる | 組織のポリシーで PowerShell の実行ポリシーが固定されているときは、ファイルのプロパティで［ブロックの解除］を有効にしてから実行します（[単一 .ps1 版による配置](index.md#単一-ps1-版試験版による配置)） |
| `tebunko.bat` を使わずにショートカットから起動したが、何も起きない（zip 版） | zip を解除してから展開したか（印が残っていると起動が止まります。展開し直してください）、ショートカットの作業フォルダーが展開したフォルダか、リンク先の `-File` のパスが `scripts\tebunko\gui.ps1` かを確認します（[`tebunko.bat` を使わずに起動する](index.md#tebunkobat-を使わずに起動するzip-版)）。この方法では理由の表示（メモ帳）が出ません |
| 「Windows によって PC が保護されました」が表示される（インストーラー版） | ［詳細情報］→［実行］を選択します。インストーラーがコード署名されていないために表示されます |
| 起動操作をしても画面が表示されない | tebunko が既に起動していないか確認してください（既に起動している場合は、既存のウィンドウが前面に表示されます）。組織のポリシーで PowerShell の実行が制限されている場合や、制限言語モード（AppLocker・WDAC）で許可されていない場合は、メモ帳（Notepad）に理由が表示されます。表示された案内に従い、[制限された環境での動作](index.md#制限された環境での動作)を確かめたうえで、[安全性](../safety/index.md) の資料を添えて情報システム部門に確認するか、zip の展開し直しなどの対処をしてください。メモ帳が出ない場合（PowerShell 自体が見つからない・AppLocker の実行ファイルの規則で PowerShell の起動自体が止められている場合）は、Windows PowerShell 5.1 が有効か、Windows 自身が出す知らせが無いかを確認してください |
| 起動時に［8 設定］が表示される | 既定のワークスペースに tebunko 以外のファイルが存在します。空のフォルダを指定してください（[設定](settings.md#ワークスペース)） |

## 前の版のインデックスの知らせが出る場合

| 症状 | 原因と対処 |
|---|---|
| 「前の版のインデックス（「…\index」）は、この版では使えません。…」が表示される | ワークスペースに前の版（`index` フォルダ・`content_index` フォルダにそろえる前）のインデックスが残っています。［インデックス作成を開始］を押すと、元のファイルをすべて取り込み直します。取り込み直した後は `index` フォルダを削除してかまいません |
| ［すべて更新］を押すと「前の版のインデックスは使えないため、元のファイルをすべて更新し直します。…」の確かめが出る | 上と同じ理由です。［取り込み直す］を押すと取り込み直しを始めます。ファイルが多いと時間がかかります |
| 「前の版のインデックス（高速検索用）を片付けられませんでした（…）」が表示され、インデックス作成が始まらない | 前の版の `system_index` フォルダの中のファイルを、tebunko の画面やエクスプローラーで開いています。閉じてから、もう一度［インデックス作成を開始］を押してください |
| ワークスペースの直下や `content_index` の中に、日本語の名前のファイル（前の版の `取り込み一覧.tsv` `元のフォルダ.txt` など）が残っている | 前の版はこれらのファイル名が日本語でした。この版はこれらのファイルを tebunko のものと見分けられず、クロール対象の下にあると本文として取り込んでしまい、検索結果が二重にヒットします。削除してください |

## インデックス作成が完了しない場合

| 症状 | 原因と対処 |
|---|---|
| 「チェックの付いたクロール対象フォルダがありません」 | ［1 インデックス管理］で、更新するインデックスの［作成］にチェックを付けてください |
| 「クロール対象フォルダが見つからなくなったため、インデックス作成を中止しました」 | 処理中にネットワークの切断や USB メモリの取り外しなどにより、フォルダにアクセスできなくなりました。フォルダにアクセスできる状態に戻してから再実行すると、続きから更新します |
| 「設定ファイルが壊れていたため、既定の設定で起動しました」 | 起動時に設定ファイル（`setting.config`）が読めなかったため、`setting.config.broken-<日時>` という名前に退避し、既定の設定で起動しました。ワークスペースの場所・登録したフォルダなども既定に戻っています。元に戻すには、tebunko を閉じてから退避したファイルを直して `setting.config` に置き換え、開き直してください。直さずに、画面から設定し直しても構いません |
| 「setting.config を読み込めません」 | tebunko を使っている途中で、設定ファイルが読めなくなりました（手で編集して書き損じた等）。内容を修正してください。直せないときは tebunko を閉じ、`setting.config` を削除して開き直すと、既定の設定で起動します |
| 画面を閉じたら処理が停止した | インデックス作成は tebunko のプロセス内で実行されるため、画面を閉じると中断されます。［続きから再開］で残りを更新してください |
| インデックス作成のたびに「まだ取り込んでいないファイルがあります」と出る／`.ppt` が取り込まれない | PowerPoint を開いたままインデックス作成をすると、PowerPoint が要るファイル（旧形式の `.ppt` など）は接続せずに取り込まず、そのまま残します（利用者の PowerPoint の内容・設定は変わりません）。PowerPoint を閉じてからインデックス作成を始めると取り込みます |
| 特定のファイルで処理が進まない | 1 ファイルの処理が 10 分を超えると、そのファイルを失敗として次のファイルに進みます。完了を待つか、［中止］してください。残った Office は、次に tebunko を起動したときの確認で終了できます |
| 処理に時間がかかる | サイズの大きいファイルが多い場合は時間を要します。2 回目以降は追加・変更されたファイルのみを更新するため、短時間で完了します |

停止した原因の詳細は、［ログを開く］で `indexing_log.txt` を確認してください。

## 更新に失敗したファイルがある場合

［1 インデックス管理］の「⚠ 更新に失敗したファイル」に表示される「失敗の原因」ごとの対処方法です。

| 失敗の原因（冒頭部分） | 対処 |
|---|---|
| 読み取りパスワードが設定されているため開けません | 更新できません。パスワードを解除したコピーであれば更新できます |
| IRM・秘密度ラベルで暗号化されているため更新できません | 更新できません。保護を解除したコピーであれば更新できます |
| 暗号化されているか壊れているため更新できません | 透過型のファイル暗号化製品で暗号化されたファイルの見込みがあります。製品の設定で Office がそのファイルを平文で開けるようにするか、暗号化を解除したコピーを取り込んでください |
| ファイルを暗号化する製品が一時ファイルを暗号化したため更新できません | 上と同じ製品が、変換の途中でできる一時ファイルまで暗号化しています。同上の対処をしてください |
| ファイルが壊れているか、拡張子と中身の形式が一致していません | 拡張子を修正するか、正常なファイルに差し替えてください |
| ほかのアプリ・利用者がファイルを使用中のため読めません | ファイルを閉じてから、再度更新してください |
| ファイルを読むアクセス権がありません | フォルダの管理者に読み取り権限の付与を依頼してください |
| ファイルが見つかりません | 更新中にファイルが移動または削除されました。次回のインデックス作成で一覧から自動的に除外されます |
| 10 分以内に更新が終わらなかったため中止しました | 該当ファイルを Office で開き、サイズや表示されるダイアログの有無を確認してください |
| Officeアプリ（Excel・Word・PowerPoint）を起動できませんでした | Office のインストール状態とライセンス認証の状態を確認してください |
| Officeアプリが応答しませんでした | tebunko を起動し直し、残った Office の確認で［終了する］を選んでから、再度更新してください |
| シート・文書が大きすぎて更新できません | シートを分割するか、メモリ容量の大きい PC で更新してください |

原因を解消した後、「インデックス作成の確認」で「前回更新に失敗し、その後更新されていないファイル N 件も再更新する」にチェックを付けて実行します（ファイルを更新した場合は、チェックが無くても取り込みの対象となります）。

すべてのメッセージとその意味は [エラーメッセージ一覧](../design/indexing/errors.md) を参照してください。

## 検索結果に表示されない場合

| 確認項目 | 内容 |
|---|---|
| 検索対象 | 画面左側の「検索対象」で、対象のインデックス・フォルダにチェックが付いているか確認してください |
| 種類 | 種類のチップ（Excel・Word・PowerPoint・テキスト）を外している場合、外した種類のファイルは検索対象になりません |
| インデックスの更新 | 元のファイルの変更は、次回のインデックス作成後に反映されます |
| ［図形］［コメント］ | 図形・コメント内の文字は、これらが有効な場合のみ検索対象となります |
| 表示形式 | Excel の数値は表示形式どおり（`1,234` など）に検索します（[制限事項](limitations.md#excel-の数値)） |
| 取り込みの失敗 | 該当ファイルが「更新に失敗したファイル」に含まれていないか確認してください |

## 高速検索が「使用不可」となる場合

正規表現による検索、または 1 文字の検索ワードでは、高速検索は使用しません。それ以外の場合は、Windows Search がワークスペースの `system_index` を索引付けしているか確認してください（[高速検索](fast-search.md)）。使用不可の場合も、検索結果は同一です。インデックスごとの理由は、［1 インデックス管理］の一覧の「高速検索」列のバッジにカーソルを合わせると確認できます。

## 元のファイルを開けない場合

- 「<ファイル名> が見つかりません」と表示される：元のフォルダが移動または名前変更されています。［フォルダを選ぶ］で移動先を指定してください（[元のファイルを開く](open-files.md#元のファイルが見つからない場合)）。
- 他の利用者が編集中で開けない：開き方を［新規（元のファイルを占有しない）］に変更してください。
- Excel が応答しない：tebunko を起動し直したときの確認で［終了する］を選んでから、再度開いてください。確認が出ないときは、タスクマネージャーで終了してください。

## ログファイル

ログはワークスペース（既定：`%USERPROFILE%\Documents\tebunko_ws`）に保存されます。

| ファイル | 内容 |
|---|---|
| `indexing_log.txt` | インデックス作成の経過と、更新に失敗したファイルの原因。インデックス作成ごとに上書きされます。［ログを開く］で表示できます |
| `gui_error_log.txt` | 画面で発生した予期しないエラーの記録。追記されます |
| `startup_error.txt`（`%LOCALAPPDATA%\tebunko\startup_error.txt`。書き込めない場合は `%TEMP%\tebunko_startup_error.txt`） | 画面が表示される前に起動が失敗したときの記録。起動に失敗するたびに書き直されます。ワークスペースの外（固定の場所）にあります |
