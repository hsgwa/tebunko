# 元のファイルを開く

検索結果から、元の Office ファイルの該当箇所を開きます。

## 開き方

次のどれかで開きます。

- 結果の行をダブルクリックする
- 結果の行を選んで Enter を押す
- プレビューの［Excel で開く］（Word・PowerPoint では［開く］）を押す
- 右クリックして［元のファイルを開く（編集する）］などを選ぶ

Excel は、該当のシートのセルを選んだ状態で開きます。

## 開き方を選ぶ

プレビューの横にある「開き方」で、ダブルクリック・Enter で開くときの開き方を選べます。選んだものは、次に起動したときも使います。

| 開き方 | 内容 |
|---|---|
| ［通常（編集する）］ | 元のファイルをそのまま開きます。編集して上書き保存できます |
| ［読み取り専用］ | 元のファイルを読み取り専用で開きます。誤って上書き保存することがありません（編集するときは名前を付けて保存します） |
| ［新規（元のファイルを占有しない）］ | 元のファイルを基にした新しい（無題の）ブック・文書として開きます。元のファイルを占有しないため、ほかの人が編集中でも開け、ほかの人の編集も妨げません。保存するときは名前を付けて保存します |

共有フォルダのファイルを見るだけなら、［読み取り専用］か［新規］にしておくと安心です。

## 右クリックのメニュー

結果の行を右クリックすると、次のメニューが出ます。

| メニュー | 内容 |
|---|---|
| ［元のファイルを開く（編集する）］ | 通常の開き方で開く |
| ［読み取り専用で開く］ | 読み取り専用で開く |
| ［新規で開く］ | 新しいブック・文書として開く |
| ［フォルダを開く］ | 元のファイルのあるフォルダをエクスプローラーで開く |
| ［選択行をコピー］（Ctrl+C） | 選んだ行をコピーする。見出しの行を選んでいれば、そのファイルの行をすべて |
| ［ファイルのパスをコピー］ | 元のファイルのパスをコピーする |

プレビューを右クリックすると、［選んだセルをコピー］［この行をコピー］が使えます。

## 元のファイルが見つからないとき

元のフォルダを移したり、名前を変えたりすると、「<ファイル名> が見つかりません」と表示されます。［フォルダを選ぶ］で、移した先のフォルダ（元のフォルダでも、その下のどのフォルダでもかまいません）を選ぶと、tebunko がファイルを探し、見つかればそのまま開きます。

見つかったときは、そのインデックスの元のフォルダを新しい場所に記録し直します。同じインデックスのほかのファイルも、そのまま開けるようになります。インデックスを作り直す必要はありません。

!!! tip "フォルダを移すと分かっているとき"
    先に［1 インデックス管理］の［編集…］で元のフォルダを新しい場所に変えておくと、このダイアログは出ません（[インデックスを作る](indexing.md#名前や場所を変える編集)）。
