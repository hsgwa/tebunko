# 元のファイルを開く

検索結果から、元のファイルの該当箇所を開く方法を説明します。

## 操作方法

次のいずれかの操作で開きます。

- 検索結果の行をダブルクリックする
- 検索結果の行を選択して Enter キーを押す
- プレビューの［開く］を選択する
- 右クリックメニューから開き方を選択する

Excel の場合は、該当するシートのセルを選択した状態で開きます。

## 開き方の指定

プレビューの［開く ▾］のメニューで開き方（［開く］［新規で開く］［読み取り専用で開く］）を選ぶと、その開き方で開き、ダブルクリックまたは Enter キーで開く際の方法にもなります。指定は保存され、次回起動時にも引き継がれます。

| 開き方 | 内容 |
|---|---|
| ［開く］ | 元のファイルをそのまま開きます。編集して上書き保存できます |
| ［読み取り専用で開く］ | 元のファイルを読み取り専用で開きます。誤って上書き保存されることはありません（編集内容を保存する場合は、名前を付けて保存します） |
| ［新規で開く］ | Excel・Word・PowerPoint は、元のファイルを基にした新規（無題）のブック・文書として開きます。テキスト・PDF などは、元のファイルのコピーを作ってそのコピーを開きます（コピーは作業フォルダの `tmp` の下に `<元の名前>（コピー 年月日-時分）.<拡張子>` の名前で置き、最後に使ってから 1 日より古いものは次の起動時に片付けます。ファイル名・フォルダが長すぎるなどでコピーを作れなかったときは、理由を示して［開く］を案内します）。ステータスにコピーの場所を表示します。元のファイルを占有しないため、他の利用者が編集中でも開くことができ、他の利用者の編集も妨げません。Office の新規の文書は、保存する場合に名前を付けて保存します。テキスト・PDF のコピーは上書き保存でき、書かれるのはコピーで、元のファイルは変わりません |

共有フォルダのファイルを閲覧する用途では、［読み取り専用で開く］または［新規で開く］の使用を推奨します。

テキストファイル（[対応するテキストの拡張子](limitations.md#対応するテキストの拡張子)）は、［開く］では既定のアプリでそのまま開きます。［読み取り専用で開く］は Office のファイルだけに表示します。［新規で開く］では、元のファイルのコピーを開きます。ただし `.bat` `.cmd` `.ps1` `.vbs` `.js` `.reg` `.sh` `.py` `.rb` `.pl` `.php` `.lua` `.mjs` `.psm1` `.psd1` は、開くと実行・登録になってしまうため、既定のアプリではなく固定のパスのメモ帳で開きます（ステータスに「メモ帳で開きました」と表示）。該当の行へは移動しません。

PDF ファイルも、［開く］では既定のアプリでそのまま開きます（ステータスに「開きました」と表示）。［新規で開く］では、元のファイルのコピーを開きます。該当のページへは移動しません。

## 右クリックメニュー

検索結果の行を右クリックすると、次のメニューを表示します。

| メニュー | 内容 |
|---|---|
| ［開く］ | 通常の方法で開く |
| ［読み取り専用で開く］ | 読み取り専用で開く（Office のファイルだけに表示） |
| ［新規で開く］ | 新規のブック・文書として開く |
| ［フォルダを開く］ | 元のファイルの格納フォルダをエクスプローラーで開く |
| ［選んだ行をコピー］ | 選択した行をコピーする |
| ［ファイルのパスをコピー］ | 元のファイルのパスをコピーする |

先頭に太字で出る項目が、設定の「ファイルの開き方」で選んだ開き方です（ダブルクリックと同じ）。

ファイルごとの見出しの行を右クリックすると、［開く］［新規で開く］［読み取り専用で開く］（Office のファイルだけ）［フォルダを開く］［ファイルのパスをコピー］と、そのファイルの結果を閉じる・開く項目を表示します。

プレビューを右クリックすると、先頭の［元のファイルのこの場所を開く］のほか、［選んだセルをコピー］［この行をコピー］を使用できます。

## もらったインデックスを開くとき

`store` フォルダに手でコピーしたインデックスなど、この PC で作っていないインデックスの結果を初めて開くときは、開く前に「<ファイル名> の元のフォルダを確かめてください」と表示します。元のフォルダはそのインデックスを作った人が書いたものです。心当たりのある場所なら［このフォルダを使う］を選びます。次からは、同じインデックスについて聞きません。心当たりのない場所なら［フォルダを選ぶ］で今ある場所を指定するか、キャンセルします（「開くのをやめました」と表示し、何も開きません）。

元のフォルダが共有フォルダのときは、開くと Windows がその共有フォルダに接続し、サインイン情報を送ることがあります。知らない場所は選ばないでください。

この PC で作っていないインデックスの Excel（`.xlsm` `.xlsb` `.xls`）・Word（`.docm` `.doc`）・PowerPoint（`.pptm` `.ppt`）のファイルは、マクロを持てる形式のため、開き方によらず読み取り専用で開きます。読み取り専用で開けないときは、開かずに「読み取り専用で開けなかったため、開きませんでした」と表示します。

## 元のファイルが見つからない場合

元のフォルダの移動や名前の変更により元のファイルが見つからない場合は、「<ファイル名> が見つかりません」と表示します。［フォルダを選ぶ］で移動先のフォルダ（元のフォルダ、またはその配下の任意のフォルダ）を指定すると、tebunko がファイルを検索し、見つかった場合はそのまま開きます。

![「見積.xlsx が見つかりません」のダイアログ。［フォルダを選ぶ］で今ある場所を指定できる](../images/screens/search-tab/missing-source.png)

ファイルが見つかった場合は、そのインデックスの元のフォルダを移動先に更新します。以降は、同じインデックスの他のファイルも同様に開けます。インデックスを再作成する必要はありません。

!!! tip "フォルダを移動する予定がある場合"
    事前に［インデックス管理］の詳細でフォルダパスを移動先に変更しておくと、このダイアログは表示されません（[名前と場所の変更](indexing.md#名前と場所の変更)）。
