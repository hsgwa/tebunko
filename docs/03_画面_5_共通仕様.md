## 8. 設定ファイル・履歴の読み書き

| ファイル | 画面での扱い |
|---|---|
| `setting.config` | 画面が読み書きし、変換処理は変換対象フォルダを読む。UTF-8 の JSON で、キーは次のとおり。<br>・`targetFolders`：変換対象フォルダ `{name, path, enabled}` の配列（［1 インデックス作成］。`getTargetFolders` / `writeTargetFolders`）。`name` はインデックス名、`path` は今の置き場所（分けて持つ）。`enabled` が `false` はチェックなし<br>・`indexSources`：変換しないインデックスの元のフォルダ `{name, path}` の配列（[4.5.2](03_画面_2_検索タブ_1_元のファイルを開く.md#452-元のファイルが見つからないとき元のフォルダを設定する)。`readIndexSources` / `writeIndexSources` / `setIndexSourceFolder`）<br>・`indexFolders`：検索対象インデックスのフォルダの配列（［場所の設定…］のダイアログ、4.8。`readIndexFolders` / `writeIndexFolders`）。空は「work\index を検索」の意味<br>・`searchExcludes`：検索対象のツリーでチェックを外したフォルダ `{path, subfolders}` の配列（4.10。`readSearchExcludes` / `writeSearchExcludes`）。無ければすべてチェックあり<br>・`useRegex`：［正規表現を使う］の状態（true / false。`readSearchOption` / `writeSearchOption`）。無ければオフ<br>・`caseSensitive`：［大文字と小文字を区別］の状態（true / false。同上）。無ければオフ<br>・`fileFilter`：「対象ファイル」の指定（文字列。同上）。無ければ空（すべて）<br>・`openMode`：［開き方］の状態（`normal` / `readOnly` / `new`。`readOpenMode` / `writeOpenMode`、[4.5](03_画面_2_検索タブ_1_元のファイルを開く.md#45-元のファイルを開く)）。無い・知らない値なら `normal`（通常） |
| `config/検索ワード.txt` | **使わない**（`2_検索.bat` とともに廃止した） |
| `work/検索履歴.txt`（新規） | 4.7 のとおり |

| 項目 | 仕様 |
|---|---|
| 読み込み | `setting.config` が無ければ、以前の設定ファイル（`config/変換対象フォルダパス.txt`・`検索対象インデックスパス.txt`・`検索オプション.txt`）を最初に読むときに自動で `setting.config` へ移す。以降、以前のファイルは読まない。どちらも無ければ既定値（空・オフ）とし、**ファイルを作成しない** |
| 保存のタイミング | 変換対象フォルダ：追加・削除・チェックの変更のたび。検索対象インデックス：ダイアログの［OK］。検索対象のツリー：チェックを変えたとき。正規表現の使用・大文字と小文字の区別：チェックを変えたとき。［開き方］：選び直したとき（起動時の読み込みでは保存しない）。対象ファイル：欄からフォーカスが外れたときと検索したとき。インデックスの元のフォルダ：［場所を変更…］で変えたとき・検索結果からフォルダを選んで見つかったとき。インデックス名：変換の開始時（まだ決まっていないフォルダがあるとき、変換処理が保存する）。検索履歴：検索が終わったとき |
| 保存形式 | `setting.config`：保存のたびにファイルを読み直し、変えたキーだけを書き換える（ほかのキーは、ほかの画面・処理が保存した内容を保つ）。UTF-8（BOM なし）。検索履歴：各行の前後の空白を除き、空行を除く。UTF-8（BOM 付き）・CRLF（`writeListFile`） |
| 外部での編集 | ウィンドウがアクティブになったとき、保存されている変換対象フォルダの一覧を、画面が最後に読み込み・保存した一覧と比べ（`getTargetsKey`）、異なれば読み直す（画面側の変更はその場で保存済みのため、失われるものは無い）。検索対象インデックスは検索のたびに読む |

## 9. キーボード操作

| キー | 動作 |
|---|---|
| Enter（検索ワード欄） | 検索する |
| ↑ / ↓（検索ワード欄） | 検索履歴を選ぶ |
| Esc | 検索中なら中止する（ウィンドウは閉じない） |
| Ctrl+F | 検索ワード欄にフォーカスを移し、全選択する（［2 検索］タブに切り替える） |
| Ctrl+Shift+F | 絞り込み欄にフォーカスを移す |
| Enter（結果の表） | 元のファイルの該当箇所を開く |
| Ctrl+C（結果の表） | 選択行をコピーする（4.5） |
| F5 | ［1 インデックス作成］では状態を、［9 Office 強制終了］では一覧を取り直す |
| Ctrl+Tab / Ctrl+Shift+Tab | タブを切り替える |
| Delete | 検索対象インデックスの設定ダイアログで、選択中のフォルダを削除する |
| スペース | 検索対象のツリーで、選択中の項目のチェックを切り替える（4.10） |

変換と強制終了は影響が大きいため、ショートカットキーを設けない。

## 10. 表示・アクセシビリティ

- フォントは Yu Gothic UI（無ければ Meiryo UI）、13 px とする。結果の表は 12 px とする。
- WPF は高 DPI に自動で対応するため、表示倍率 125 %・150 % でもぼやけない。
- 状態は**色だけで表さない**。`✓` `✗` `⚠` `⏸` の記号と文言を併記する。一致箇所の強調は背景色に加えて太字にする。
- 文言は、対象が Word・PowerPoint にも広がったため「Excel」ではなく「Office ファイル」とする。
- 入力の誤りや注意は入力欄の下やステータスに表示する。ダイアログは確認が必要な操作（3 章の［削除］、3.1・3.4 の変換の確認、4.5.2、5.2）に限る。
- 危険な操作（［すべて終了］）のボタンは赤枠にし、主ボタン（青）と区別する。
