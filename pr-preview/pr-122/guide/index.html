    はじめに¶

    tebunko は、Excel・Word・PowerPoint のファイルを内容の文字列で検索する Windows 用の全文検索ツールです。ファイルから抽出した文字を索引データ（インデックス）として保存しておき、検索時はインデックスのみを照合するため、ファイルを開かずに検索できます（インデックスの仕組み）。検索結果には、該当するファイル・シート（ページ・スライド）・行を表示し、元のファイルを直接開けます。

    本ページでは、動作環境とインストール手順を説明します。インストール後は クイックスタート を参照してください。

    動作環境¶

    項目 要件
    OS Windows 10 / 11（標準搭載の Windows PowerShell 5.1 で動作します）
    Microsoft Excel 必須。Excel ファイルからの文字の抽出に使用します
    Microsoft Word・PowerPoint 旧形式（.doc・.ppt）のファイルを取り込む場合のみ必要です

    管理者権限、追加のソフトウェア、PowerShell の実行ポリシーの変更、ネットワーク接続は不要です。

    対応するファイル形式¶

    種類 拡張子 検索結果に表示する場所
    Excel .xlsx / .xlsm / .xls / .xlsb シート（行・セル）
    Word .docx / .docm / .doc ページ（目安）・ヘッダー/フッター・脚注
    PowerPoint .pptx / .pptm / .ppt スライド・ノート・フッター

    インストール¶

    Releases で次の 2 形式を配布しています。ツールの本体は同一です。

    形式 用途
    インストーラー（tebunko-setup-<バージョン>.exe） インストール・更新・アンインストールを Windows の標準の手順で行う場合
    zip（tebunko-<バージョン>.zip） 実行ファイル（.exe）を導入できない環境、または共有フォルダに配置して使用する場合

    インストーラーによるインストール¶

    1. tebunko-setup-<バージョン>.exe をダウンロードして実行します。
    2. 「Windows によって PC が保護されました」と表示された場合は、［詳細情報］→［実行］を選択します（インストーラーは現在コード署名されていないため、この画面が表示されます）。
    3. 画面の指示に従って進めます。管理者権限は不要です。既定のインストール先は %LOCALAPPDATA%\Programs\tebunko です。管理者権限がある場合は、全ユーザー向けに C:\Program Files へインストールすることもできます。
    4. スタートメニューの「tebunko」から起動します。

    zip による配置¶

    1. tebunko-<バージョン>.zip をダウンロードし、任意の場所に展開します。共有フォルダにも配置できます。
    2. 展開した tebunko フォルダ内の tebunko.bat を実行します。

    初回起動時に「セキュリティの警告」が表示された場合は、［実行］を選択します。この警告を表示させない場合は、事前に tebunko.bat のプロパティで［ブロックの解除］を有効にしてください。

    zip の内容

    tebunko.bat（起動用）、scripts（ツール本体）、README.md、LICENSE を含みます。設定ファイル setting.config は、初回の設定保存時に同じフォルダに作成されます。

    画面構成¶

    画面は 4 つのタブで構成されます。タブの番号は画面の表示に対応しています。

    タブ 機能 説明
    ［1 インデックス管理］ 検索対象フォルダの登録とインデックスの作成 インデックスの作成
    ［2 検索］ 検索と、検索結果からのファイルの表示 検索・元のファイルを開く
    ［8 設定］ インデックスの保存先（ワークスペース）の変更 設定
    ［9 プロセス停止］ 残存した Excel・Word・PowerPoint のプロセスの終了 Office プロセスの停止

    起動時には、インデックスが未作成の場合、または前回のインデックス作成が中断されている場合は［1 インデックス管理］を、それ以外の場合は［2 検索］を表示します。tebunko の起動中に再度起動すると、既存のウィンドウが前面に表示されます。
