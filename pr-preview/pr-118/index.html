    tebunko でできること

    すばやく探せる

    先に文字を取り出してインデックスを作るので、検索のたびにファイルを開きません。100 万行（約 70MB）のインデックスでも 1〜2 秒で結果が出ます。

    場所まで分かる

    ファイルごとに、シート・ページ・スライドと行を表示し、一致した文字を黄色で目立たせます。ダブルクリックで元のファイルを開き、Excel は該当のセルを選んだ状態で開きます。

    図形やコメントの中も

    セルや段落だけでなく、図形・テキストボックス・コメントの文字も探せます。.xls・.doc・.ppt などの古い形式にも対応しています。

    Office があれば使える

    必要なのは Windows と Microsoft Office だけ。管理者権限も、追加のソフトも要りません。zip を展開するだけでも、インストーラーで入れても使えます。

    変わったファイルだけ取り込む

    2 回目からは、新しいファイルと変わったファイルだけを取り込みます。途中で止めても、次は続きから。作成中も検索できます。

    通信しない

    ネットワークにはつながりません。何をして何をしないかを公開し、変更のたびにテストで確かめています。

    3 ステップで使えます

    1. 1

      フォルダを登録する

      ［1 インデックス管理］で、探したいファイルが入ったフォルダを追加します。共有フォルダも登録できます。

    2. 2

      インデックスを作る

      ［インデックス作成を開始］を押すと、ファイルから文字を取り出します。300 ファイルで 3 分ほどが目安です。

    3. 3

      検索して、開く

      ［2 検索］に言葉を入れて Enter。結果の行をダブルクリックすると、元のファイルの該当箇所が開きます。
