    画面に出すメッセージの一覧¶

    扱うこと: 画面が出すメッセージ・確認・ダイアログの文言と条件の正本の入口。画面に出す文言は、このページと下の画面ごとのページにだけ書き、ほかの設計書は節へのリンクで指す（書き写すと食い違う）。扱わないこと: 確認ダイアログの形式そのもの（画面の共通の決まり）。先に読むページ: 画面の共通の決まり。利用者に出す文言を足したら、画面ごとのページに載せる（tests/meta/error_messages.Tests.ps1 が messages*.md を確かめる）。

    画面ごとのページ¶

    画面・場面 ページ
    ［インデックス管理］（一覧・詳細・追加・編集・削除・更新の確認・拡張子） messages-index.md
    インデックス作成の実行（帯・確認の合計・中止・終わり） messages-indexing.md
    インデックスの書き出し・読み込み・名前変更・ワークスペースの変更で断られたとき messages-index-ops.md
    ［検索］・検索結果から開く・コピー・出力 messages-search.md
    ［設定］（エディタの指定） 下の「設定」
    画面全体（状態・残った Office・予期しないエラー・起動の失敗） 下の「画面全体」

    ログの文言¶

    画面のログ欄・ファイルに書くインデックス作成のログの文言の正本は、エラーの一覧（errors.md）と、警告・お知らせのlog-warnings.mdにある。ここには移さない。予期しないエラーを記録するファイル gui_error_log.txt に書く文は、下の「予期しないエラー」の行（ダイアログと同じ文）が正本で、ファイルの置き場と形は入出力ファイルにある。コンソールの出力は扱わない。
