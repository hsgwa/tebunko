    ［インデックス管理］タブ¶

    細かい仕様は ［インデックス管理］タブ にある。

    目的¶

    検索の対象にするフォルダを登録し、インデックスを作る。インデックスの有無・更新中・中断・失敗の状態を、この画面で見分けられる。

    部品と並び¶

    • 上に「更新の帯」。右の領域の上端いっぱいの高さ 40 の 1 行で、左端に状態の色の太い線とアイコンを置く。更新中（青）・中断（黄）・終わった（緑）を 1 枚で出す。更新中は進み具合と［中止］、中断は［続きから再開］を右に置く。帯が無いときは場所を取らない。
    • その下に「インデックス一覧」。行のチェックは［アクション ▾］で操作する行を選ぶ一時の選び（保存しない。初めは全部外れている）。列は チェック・インデックス名・パス・ファイル数・最終更新・ステータス・高速検索・操作。表の下に 登録済み: N フォルダ と 合計: N ファイル。
    • 一覧の右上に［すべて更新］［アクション ▾］［＋ フォルダを追加］。［アクション ▾］のメニューは［更新］［エクスポート…］［インポート…］と、区切りの下に［削除…］。見出しの横に N / M 件を選択中、見出し行の左端に全選択のチェック。［更新］［エクスポート…］［削除…］はチェックを付けた行に対して動く。インデックスが 1 件も無いときは、表の中の案内にも同じ動きの［＋ フォルダを追加］を置く。行の右端のボタンは［更新］［中止］だけ。行の右クリックのメニューに［編集…］［エクスポート…］［削除…］。一覧へのドラッグ＆ドロップでも追加できる。
    • 下に「インデックスの状態」（選んだ行の詳細。選んでいなければ、すべてのインデックスの合計）。
    • ナビの［インデックス管理］の横に、更新中は ● 66%、中断中は 中断、失敗があるだけなら 失敗。失敗があると、失敗したファイルの一覧と「失敗の原因」の列が出る。

    状態と遷移¶

    state "index-tab/delete-confirm" as del
    state "index-tab/start-confirm" as start

    state "index-tab/done" as done
    state "index-tab/failed" as failed
    empty --> add: ［＋ フォルダを追加］（11）
    add --> normal: ［OK］
    normal --> edit: ［編集…］（14）
    edit --> normal: ［OK］
    normal --> del: ［削除］（15）
    del --> normal: ［削除する］
    normal --> start: 開始（17）
    start --> running: ［更新を開始］
    running --> stop: ［中止］（19）
    stop --> running: ［キャンセル］
    stop --> interrupted: ［中止する］
    interrupted --> start: 続きから再開
    running --> done: 失敗なし（18）
    running --> failed: 失敗あり（18）
    • 追加のダイアログで入力が足りないと、ダイアログの中に注意が出る（index-tab/add-error。12）。
    • 行のチェックを付けると、［アクション ▾］の［更新］［エクスポート…］［削除…］がその行に動く（index-tab/checked。16）。［すべて更新］はチェックと関係なく全部を更新する。
    • 更新中は［＋ フォルダを追加］と［アクション ▾］のメニューの項目、ほかの行の［更新］、［すべて更新］が押せない（20）。更新中の行には［中止］が出て、押すと回全体を止める。更新が終わると、また押せる。
    • 前回の作成が中断したまま起動すると、この画面が選ばれて index-tab/interrupted になる（4）。 状態の判定と画面の更新は状態の判定と操作の流れ、メッセージの一覧はメッセージ一覧にあり、ここには書き写さない。

    表示する文言¶

    状態 文言
    一覧が空 「フォルダを追加してください」「検索したいフォルダを追加すると、ここに表示されます。」と［＋ フォルダを追加］、［すべて更新］の下に「フォルダを追加すると更新できます」。詳細は「まだインデックスがありません。」
    追加 「インデックスの追加」。欄は「元のフォルダ（Office ファイルのある場所）」「インデックス名」。注意は「元のフォルダを指定してください。」
    編集 「インデックスの編集」。名前と場所だけを変えられる旨の注記
    削除の確認 「「営業」のインデックスを削除しますか？」「元のファイルは削除されません。」、［削除する］［キャンセル］
    更新の確認 「インデックス更新の確認」「更新対象: 1 フォルダ / 3 ファイル（最新のフォルダは更新しません）」、［更新を開始］［キャンセル］
    更新中 「インデックスを更新しています（18 / 300 件）」「残り 1 分未満」、［中止］
    中止の確認 「インデックスの更新を中止しますか？」、［中止する］［キャンセル］
    中断 「更新を中断しました（残り 265 件）」、［続きから再開］
    完了 「更新が終わりました（成功 3 件 / 失敗 0 件）」、［ログを開く］
    失敗 「更新に失敗したファイル 1 件」と「失敗の原因」の列
