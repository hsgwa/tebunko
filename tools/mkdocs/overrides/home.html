Office 文書の中身を、
数秒で横断検索。

共有フォルダに蓄積された数千の Excel・Word・PowerPoint から、探している言葉がどのファイルの、どのシートの、何行目にあるかを一覧で表示。ダブルクリックで、その箇所を直接開きます。

こんな場面で

ファイルを 1 つずつ開いて探していた時間が、検索 1 回で済みます。

{% include ".icons/material/file-table-outline.svg" %}

過去の見積書から単価を調べる

取引先名や品名で検索し、該当する見積書のシートと行を特定。数年分の Excel を開き直す必要はありません。

{% include ".icons/material/book-search-outline.svg" %}

規程や手順書の記載箇所を探す

キーワードで Word の規程集を横断検索し、該当する文書とページを一覧で確認。その場で元の文書を開けます。

{% include ".icons/material/folder-account-outline.svg" %}

引き継いだ資料の全体像をつかむ

顧客名や案件名で検索するだけで、関連する提案書・議事録・報告書がまとめて見つかります。

tebunko の特長

{% include ".icons/material/lightning-bolt.svg" %}

数秒で結果が出る

文書の文字をあらかじめ索引（インデックス）にまとめておくため、100 万行規模でも検索は 1〜2 秒。検索のたびにファイルを開く待ち時間はありません。

{% include ".icons/material/crosshairs-gps.svg" %}

該当箇所へ直行

ファイル・シート（ページ・スライド）・行まで特定し、一致した文字を強調表示。Excel は該当セルを選択した状態で開きます。

{% include ".icons/material/shape-outline.svg" %}

図形やコメントの中まで

セルや本文に加え、図形・テキストボックス・コメント内の文字も検索対象。.xls・.doc・.ppt の旧形式にも対応します。

{% include ".icons/material/briefcase-check-outline.svg" %}

会社の PC でそのまま使える

必要なのは Windows と Microsoft Office だけ。管理者権限、追加のソフトウェア、設定の変更は一切不要です。

{% include ".icons/material/update.svg" %}

更新は変更分だけ

2 回目以降は、追加・変更されたファイルだけを取り込み。変更が無ければ数秒で、常に最新の内容を検索できます。

{% include ".icons/material/shield-check-outline.svg" %}

外部と通信しない

ネットワーク通信は一切行いません。処理の範囲をすべて公開し、変更のたびに自動テストで検証しています。

使い始めるまで 3 ステップ

  1. 1

    フォルダを登録

    検索したいファイルがあるフォルダを追加します。共有フォルダやネットワークドライブにも対応しています。

  2. 2

    インデックスを作成

    ボタン 1 つで、ファイルの文字を検索用の索引にまとめます。300 ファイルで約 3 分。作成中も検索できます。

  3. 3

    検索して開く

    言葉を入力して Enter。結果をダブルクリックすれば、元のファイルの該当箇所が開きます。
