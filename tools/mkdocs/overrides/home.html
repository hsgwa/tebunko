どこに書いてあるか、
すぐ見つかる。

Excel・Word・PowerPoint の中身をまとめて検索し、その言葉が書かれたファイル・シート・行を一覧に。ダブルクリックでその箇所が開き、そのまま編集できます。

探して、そのまま編集へ

ファイルを 1 つずつ開いて探す必要はありません。

  1. 1

    言葉を入れて検索

    探したい言葉を入力して Enter。登録したフォルダの Excel・Word・PowerPoint をまとめて検索します。100 万行規模でも 1〜2 秒です。

  2. 2

    書いてある場所が分かる

    見つかった箇所を、ファイル・シート（ページ・スライド）・行の単位で一覧表示。一致した文字は強調され、前後の内容もその場で確認できます。

  3. 3

    そのまま開いて編集

    結果をダブルクリックすると、元のファイルの該当箇所が開きます。Excel は該当セルを選択した状態で開くので、すぐに編集できます。

会社の PC にも、安心して

{% include ".icons/material/laptop.svg" %}

PC の中で完結

検索も索引の作成も、すべて手元の PC の中で行います。ネットワーク通信は一切行わず、文書が外部に送られることはありません。

{% include ".icons/material/package-variant-closed.svg" %}

インストール不要・.exe なし

zip を展開するだけで使えます。zip 版は PowerShell のスクリプトと画面定義だけで、実行ファイル（.exe・.dll）を含みません。管理者権限も不要です。

{% include ".icons/material/shield-check-outline.svg" %}

処理の範囲を公開

何をして何をしないかを公開し、変更のたびに自動テストで検証しています。元のファイルを書き換えることもありません。

図形やコメントの中まで

セルや本文に加え、図形・テキストボックス・コメント内の文字も検索。.xls・.doc・.ppt の旧形式にも対応します。

{% include ".icons/material/update.svg" %}

更新は変更分だけ

2 回目以降は、追加・変更されたファイルだけを取り込み。変更が無ければ数秒で、最新の内容を検索できます。

{% include ".icons/material/folder-network-outline.svg" %}

共有フォルダに対応

ネットワークドライブや共有フォルダのファイルも検索できます。作成した索引は、複数の利用者で共有することもできます。

使い始めるまで

  1. 1

    ダウンロードして展開

    zip を展開して tebunko.bat を実行します。インストーラー版も選べます。

  2. 2

    フォルダを登録

    検索したいファイルがあるフォルダを追加します。

  3. 3

    索引（インデックス）を作成

    ボタン 1 つで、検索用の索引を作ります。300 ファイルで約 3 分。以降はすぐに検索できます。
