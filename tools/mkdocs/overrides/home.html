Office 文書の
全文検索ツール

Excel・Word・PowerPoint のファイルを内容の文字列で横断検索し、該当するファイル・シート（ページ・スライド）・行を特定します。

主な機能

{% include ".icons/material/lightning-bolt.svg" %}

インデックスによる高速検索

ファイルから抽出した文字列を索引データ（インデックス）として保存し、検索時はインデックスのみを照合します。100 万行（約 70MB）のインデックスを 1〜2 秒で検索します。

{% include ".icons/material/map-marker-outline.svg" %}

該当箇所の特定

該当箇所をファイル・シート（ページ・スライド）・行の単位で表示します。元のファイルを直接開くことができ、Excel では該当するセルを選択した状態で開きます。

{% include ".icons/material/shape-outline.svg" %}

図形・コメントも検索対象

セル・段落に加え、図形・テキストボックス・コメント内の文字列も検索します。.xls・.doc・.ppt などの旧形式にも対応しています。

{% include ".icons/material/package-variant-closed.svg" %}

導入が容易

動作に必要なのは Windows と Microsoft Office のみです。管理者権限や追加のソフトウェアは不要で、zip の展開またはインストーラーで導入できます。

{% include ".icons/material/update.svg" %}

差分取り込み

2 回目以降のインデックス作成では、追加・変更されたファイルのみを取り込みます。中断した処理は次回に再開でき、作成中も検索を実行できます。

{% include ".icons/material/shield-check-outline.svg" %}

ネットワーク通信なし

ネットワーク通信を一切行いません。処理の範囲を公開し、変更のたびに自動テストで検証しています。

利用の流れ

  1. 1

    フォルダの登録

    ［1 インデックス管理］で、検索対象のファイルを格納したフォルダを登録します。共有フォルダにも対応しています。

  2. 2

    インデックスの作成

    ［インデックス作成を開始］で、ファイルから文字列を抽出してインデックスを作成します。所要時間の目安は 300 ファイルで約 3 分です。

  3. 3

    検索と表示

    ［2 検索］で検索ワードを入力して検索します。検索結果から、元のファイルの該当箇所を開きます。
