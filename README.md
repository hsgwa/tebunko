# win_grep

Office ファイルを「場所」ごとに TSV へ変換してインデックス化し、文字列を一括検索するツールです。
操作はすべて画面（`win_grep.bat`）から行います。

| 種類 | 拡張子 | 場所（検索結果の「場所」列） |
|---|---|---|
| Excel | .xlsx / .xlsm / .xls / .xlsb | シート |
| Word | .docx / .docm / .doc | ページ（目安）・ヘッダー/フッター・脚注 |
| PowerPoint | .pptx / .pptm / .ppt | スライド・ノート・フッター |

Windows PowerShell 5.1 と Microsoft Excel が必要です（追加のインストールは不要です）。
Word・PowerPoint は、旧形式（.doc / .ppt）やパスワード付きのファイルを変換するときだけ使います（.docx / .pptx は Word・PowerPoint が無くても変換できます）。

## フォルダ構成

```
win_grep/
├─ win_grep.bat             # 画面を開く（インデックス作成・検索・Office 強制終了）
├─ setting.config         # 画面が保存する設定（自動作成。git 管理外）
├─ scripts/               # PowerShell 本体
│   ├─ config_gui.ps1     # 画面（config_gui.xaml / config_gui_index.xaml が画面の定義）
│   ├─ office_to_tsv.ps1  # 変換処理（画面がウィンドウ無しで起動する）
│   ├─ office_reader.ps1  # Word・PowerPoint の読み取り
│   └─ common.ps1         # パス定義・共通関数
├─ tests/                 # Pester テスト
├─ work/                  # 自動生成（git 管理外）。消せば最初からやり直し
│   ├─ index/             # 変換済み TSV（元のフォルダ.txt ごと別の PC へコピーして検索できる）
│   ├─ 変換一覧.tsv       # 各ファイルの更新日時・状態（Excel で開ける）
│   └─ 変換ログ.txt       # 直近の変換の記録
└─ output/                # 検索結果（git 管理外）
    └─ 検索結果.txt
```

## 使い方

`win_grep.bat` をダブルクリックすると画面が開きます。

### 1 インデックス作成

変換したいフォルダを追加し（パスの貼り付け・［参照…］・ドラッグ＆ドロップ）、チェックを付けて［変換を開始］を押します。
変換は裏で実行され、画面に進み具合（件数・残り時間）が表示されます。途中で止めるときは［中止］を押します（変換中のファイルが終わったところで止まり、次回は続きから変換します）。

- チェックを付けたフォルダごとに `work/index/<フォルダ名>/` に TSV ができます。
  チェックを外したフォルダは変換しませんが、インデックスは残ります（検索対象にも残ります）。
  一覧から削除したフォルダは、次の変換時にインデックスも削除します。
- 各ファイルの更新日時・サイズ・状態（未変換・済・失敗）を `work/変換一覧.tsv` に記録します。
  2 回目以降は、この一覧と比べて**更新されたファイル・新しいファイルだけ**を変換します。
  元ファイルを削除・名前変更した場合は、古い TSV を削除します。
- **Excel・Word・PowerPoint のフォルダを丸ごと移した場合**（別のドライブ・共有フォルダへ移動した、ドライブ名が変わった等）は、
  一覧でそのフォルダを選び、［場所を変更…］で新しい場所を選んでください。
  インデックスはそのまま使うので、**全件の変換をやり直しません**（次の変換では、更新されたファイルだけを変換します）。
  フォルダ名を変えて移した場合も同じです。削除して追加し直すと別のインデックスになり、全件変換になります。
- PC が止まった等で途中で終わった場合も、次回は続きから再開します
  （そのとき変換していたファイルは最後に回し、続けて 2 回止まったファイルは「失敗」にします）。
- 1 ファイルの変換に 10 分以上かかった場合（Excel が応答しなくなった等）は、Excel を強制終了して
  そのファイルを「失敗」とし、次のファイルへ進みます。
- 260 文字を超える長いパスのファイルや、名前の長いファイルも変換・検索できます（Windows の設定変更は不要）。
- **ファイルサーバーのフォルダも指定できます。** ネットワークドライブ（`Z:\見積`）でも UNC パス（`\\server\share\見積`）でもかまいません。
  同じフォルダを別の書き方で登録しても、同じフォルダとして扱うので、インデックスが二重にできることはありません。
  `%USERPROFILE%\Documents\見積` のような環境変数、`/` 区切り、`.` `..` を含むパスも、そのまま貼り付けられます。
  サーバーに一時的につながらないときは、そのフォルダだけ変換せずに続け、できているインデックスは消しません。
- 変換に失敗したファイル（パスワード付きなど）は一覧の状態が「失敗」になり、原因が「エラー」列に記録されます。
  失敗したファイルと原因は、［1 インデックス作成］タブの「変換に失敗したファイル」の一覧にも表示されます。
  更新されない限り次回以降はスキップし、［変換を開始］のときに「失敗したファイルも再変換するか」を選べます。
- 変換を続けられないエラー（変換対象フォルダが無い等）は画面に表示されます。変換の詳しい記録は `work/変換ログ.txt` にあります。

### 2 検索

ワードを入れて Enter を押すと、結果が画面の表に出て、一致箇所が黄色で表示されます。
ダブルクリックで元のファイルを開きます（Excel は該当シート・セルを選択した状態で開く）。
［開き方］で「読み取り専用」（誤って上書きしない）や「新規」（元のファイルを基にした無題のブック・文書。元のファイルを占有しないため、ほかの人が編集中の共有ファイルも開けます）を選べます。選んだ開き方は次回も引き継ぎ、右クリックメニューからはその時だけ別の開き方でも開けます。
［正規表現を使う］をオンにしない限り、`(株)` や `1.5` も文字どおりに検索します。
サクラエディタの Grep と同じように、［大文字と小文字を区別］と
「対象ファイル」（元のファイル名のワイルドカード。例: `*.xlsx;見積;!*old*` は、.xlsx か名前に「見積」を含むファイルのうち「old」を含まないもの）で条件を指定できます。条件は次回も引き継ぎます。

- ［結果をファイルに出力］で `output/検索結果.txt`（ファイル名・場所・行番号・該当行のタブ区切り）に書き出せます。
  結果をすべて選択して Excel に貼り付けると、4 列目以降に該当行のセルが元の列の順に並びます。
  見出しの列名（A, B, C…）と行番号で、元のセル位置が分かります。セル内改行のあるセルも 1 セルのまま貼り付けられます。
- セル内改行は、正規表現の `.` にマッチします（例: `1行目.2行目`）。
- Excel のセルは**シートで表示されている形**で検索します。セルの文字は長くても（Excel の上限 32,767 文字まで）そのまま検索できますが、
  **数値のセルは表示形式によって見つからないことがあります**。表示形式が「標準」の 12 桁以上の数値はシートでも指数表記（`4901234567894` → `4.90123E+12`）になるため、その番号では検索できません。
  「#,##0」のセルも桁区切り付き（`1,234,568`）で検索します。JAN コード・伝票番号などは、表示形式を「文字列」にするか、先頭に `'` を付けて入力すると検索できます。
- 検索対象のインデックスは［変更…］で追加できます（既定は `work/index/`）。

#### インデックスを別の PC・別の場所で使う

同じ PC の中で `work/index/` を別のドライブ・フォルダへ移した場合も、下と同じ手順です
（移した先を［場所の設定…］で検索対象にすれば、そのまま検索でき、元のファイルも開けます）。

1. 変換した PC の `work/index/` フォルダを丸ごと、別の PC の好きな場所へコピーします（USB メモリ・共有フォルダなど）。
   `work/index/元のフォルダ.txt` に元のフォルダの場所が記録されているので、一緒にコピーしてください
   （古い版で作ったインデックスには無いため、一度［変換を開始］を押すと作られます）。
2. 別の PC に win_grep を置いて `win_grep.bat` を開き、［2 検索］の［変更…］でコピーしたフォルダを検索対象に追加します。
3. 検索結果をダブルクリックすると元のファイルを開きます。元のファイルが見つからない場合（ドライブ名・共有フォルダのパスが違う等）は、
   フォルダを選ぶかを聞かれます。元のファイルのあるフォルダ（変換したフォルダに当たるフォルダ、またはファイルのあるフォルダ）を選ぶと、
   その中からファイルを探して開きます。選んだフォルダは記録され、同じフォルダのほかのファイルは次から聞かれずに開けます。
   なお、ネットワークドライブと UNC パスの違いだけ（インデックスは `Z:\見積`、この PC では `\\server\share\見積`）の場合は、
   この PC に同じ共有フォルダのドライブが割り当てられていれば、聞かれずにそのまま開けます。

### 9 Office 強制終了

変換を異常終了させた場合などに残った Excel・Word・PowerPoint を、一覧から選んで終了できます。

### その他

- すべて変換し直したい場合は、`work/` フォルダを削除してから［変換を開始］を押してください。
- Word のページ番号は目安です（ファイルにページの情報が無いため、Word が保存時に記録したページ区切りと改ページから数えます）。
- SmartArt・グラフ内の文字、埋め込みオブジェクト、Word のコメントは検索対象になりません。

Invoke-Pester .\tests
