# win_grep

Excel ファイル（.xlsx / .xlsm / .xls / .xlsb）をシートごとに TSV へ変換してインデックス化し、文字列を一括検索するツールです。
Windows PowerShell 5.1 と Microsoft Excel が必要です。

## フォルダ構成

```
win_grep/
├─ 1_変換.bat             # Excel → TSV 変換（インデックス作成）
├─ 2_検索.bat             # インデックスを検索
├─ 9_Excel強制終了.bat    # 変換中断時に残った Excel プロセスを終了
├─ config/                # ユーザーが編集する設定（git 管理外）
├─ scripts/               # PowerShell 本体
│   ├─ common.ps1         # パス定義・共通関数
│   ├─ office_to_tsv.ps1
│   ├─ grep.ps1
│   └─ kill_process.ps1
├─ tests/                 # Pester テスト
├─ work/                  # 自動生成（git 管理外）。消せば最初からやり直し
│   ├─ index/             # 変換済み TSV
│   ├─ 変換対象一覧.txt
│   └─ 変換失敗一覧.txt
└─ output/                # 検索結果（git 管理外）
    └─ 検索結果.txt
```

## 使い方

1. `config/変換対象フォルダパス.txt` に変換したい Excel のあるフォルダを1行で書く。
2. `1_変換.bat` を実行する。`work/index/` に TSV ができる。
   - 2回目以降は、変換済みで更新の無いファイルをスキップする。
   - 途中で止めるときは Ctrl+C。次回は `work/変換対象一覧.txt` の続きから再開する。
   - 変換に失敗したファイル（パスワード付きなど）は `work/変換失敗一覧.txt` に記録され、
     次回実行時に「失敗分のみ再変換」か「全ファイルを対象に変換」かを選べる。
3. `config/検索ワード.txt` に検索したい文字列を1行に1つ書く（正規表現。正規表現として不正な場合は文字どおり検索）。
4. `2_検索.bat` を実行する。結果は `output/検索結果.txt`（ファイル名・シート名・該当行のタブ区切り）に出力され、自動で開く。

設定ファイルが無い場合は初回実行時に空ファイルが作られます。設定ファイルは UTF-8 で保存してください（メモ帳の既定のままで可）。
`config/検索対象インデックスパス.txt` は省略可能で、書いた場合は各行のフォルダを検索します（省略時は `work/index/`）。

ウィンドウの×ボタンで変換を閉じた場合などに Excel が残ったときは、`9_Excel強制終了.bat` を実行します。
画面に表示されていない（バックグラウンドの）Excel のみを終了するか、すべての Excel を終了するかを選べます。

すべて変換し直したい場合は `work/` フォルダを削除してから `1_変換.bat` を実行してください。
元の Excel を削除・リネームしても `work/index/` の TSV は自動では削除されません。

## テスト

```powershell
Invoke-Pester .\tests
```

Windows PowerShell 5.1 標準の Pester 3.4 で動作します。`.ps1` は UTF-8（BOM 付き）で保存してください。
